# V0.74.1 需求：标签浮层交互与记录卡片按钮对齐

- **目标版本**：V0.74.1
- **目标分支**：`feature/v0.74`
- **状态**：需求已确认，待开发
- **文档路径**：`docs/v0.74.1.md`
- **范围**：生图管理页面的单条记录卡片；仅调整标签区展示交互和相关按钮布局，不改变模型选择功能及其他既有生图能力

## 1. 背景与目标

V0.74 的记录卡片将标签输入区与「带入 / 复制 / 提交」等操作放在同一行。标签较多或标签文字较长时，标签区域可能出现滚动条、内容拥挤或影响卡片布局的问题。

V0.74.1 需要在尽量不改变现有卡片高度、图片尺寸和整体布局的前提下，固定标签区的展示尺寸，通过浮层完整查看和管理标签，并统一标签区与相关操作按钮的底部对齐。

## 2. 标签区默认状态

1. 标签区保持固定高度，不因标签数量或文字长度变化而增高，也不得推动其他记录或改变卡片高度。
2. 标签区默认不显示水平或垂直滚动条。
3. 默认状态下标签保持单行、紧凑展示；超出可见范围的标签可以被裁切或隐藏，但不得删除、丢弃或修改标签数据。
4. 标签区的添加标签入口及原有标签管理能力继续保留。
5. 本次只调整标签的展示方式，不改变标签保存、关联、筛选和其他业务规则。

## 3. 完整标签浮层

### 3.1 触发方式

- 鼠标悬浮在标签区时，显示该记录的完整标签浮层。
- 当用户点击标签区框时，浮层切换为固定状态；鼠标移开标签区或浮层后仍然保持显示。
- 固定状态下，只有用户点击浮层及标签区之外的位置，浮层才关闭。
- 未固定的悬浮预览，在鼠标同时离开标签区和浮层后关闭。
- 点击标签区或浮层内部的交互元素，不应被误判为点击外部。

### 3.2 浮层位置和尺寸

1. 浮层优先显示在原标签区框的左侧。
2. 浮层不得遮挡原标签区框；原标签区的位置、尺寸和卡片高度均保持不变。
3. 浮层应在原标签区之外覆盖显示，不得通过撑开卡片或推动其他记录来容纳浮层。
4. 浮层中完整显示当前记录的全部标签，允许多行排列，标签文字不得因默认标签区的尺寸限制而被截断。
5. 当窗口边缘空间不足时，应在尽量保持浮层位于左侧且不遮挡标签区的前提下调整浮层尺寸或位置，确保浮层尽可能处于可视区域内。
6. 浮层应有清晰的背景、边界和层级，避免与卡片内容混淆。

### 3.3 浮层内标签操作

1. 浮层中每个标签继续显示原有的删除入口「×」。
2. 用户点击「×」后，删除对应标签；浮层和原标签区应同步更新。
3. 删除操作属于浮层内部操作，不得因事件冒泡而立即触发点击外部关闭。
4. 删除一个标签不得误删其他标签，也不得影响其他记录的标签。
5. 标签全部删除后，界面应正确显示空状态；不得残留已删除的标签。
6. 浮层内的标签操作继续使用现有标签业务逻辑，不另建一套标签存储或删除规则。

## 4. 标签区与按钮布局

1. 标签区、左侧「带入 / 复制 / 提交」按钮，以及卡片右侧「删除」按钮的底边应处于同一水平线。
2. 右侧「编辑」按钮继续位于「删除」按钮上方，不要求与左侧操作按钮底边对齐。
3. 标签区与「带入 / 复制 / 提交」保持在同一操作行；标签区使用可用的剩余空间，不能因标签数量增加而换行撑高卡片。
4. 标签区不得出现滚动条；其固定高度不能因悬浮预览或固定浮层状态而改变。
5. 尽量复用现有卡片布局和 CSS 结构，以最小范围调整对齐方式。
6. 不改变「带入 / 复制 / 提交 / 编辑 / 删除」按钮的原有功能、操作顺序和可用状态。
7. 不移动或缩小输入图、输出图，不改变图片尺寸；不因浮层出现而推动其他记录或改变卡片主体高度。

## 5. 交互边界与兼容性

- 悬浮预览和点击固定是两种不同状态；鼠标离开只会关闭未固定的预览。
- 固定状态下，点击浮层内部的标签或删除按钮，不应关闭浮层；点击浮层及标签区之外的位置才关闭。
- 浮层应绑定当前记录，不得显示其他记录的标签。
- 删除标签后，原标签区、浮层以及现有标签相关状态应保持一致。
- 继续兼容已有标签数据、模型下拉框和其他记录卡片操作。
- 不修改 Provider、模型选择、模型验证、生图请求、历史记录、筛选、排序和分页逻辑。
- 不顺带进行与本需求无关的格式、命名或结构整理。

## 6. 验收标准

### 标签区默认展示

- [ ] 标签区高度固定，不随标签数量和文字长度变化。
- [ ] 默认标签区不显示水平或垂直滚动条。
- [ ] 标签较多时，默认区域仍保持紧凑，不换行撑高卡片。
- [ ] 标签数据未因默认展示裁切而丢失。

### 浮层交互

- [ ] 鼠标悬浮标签区时，浮层显示全部标签。
- [ ] 浮层优先显示在标签框左侧，不遮挡原标签框。
- [ ] 鼠标从标签区移入浮层时，悬浮预览不会提前关闭。
- [ ] 点击标签区后，浮层固定显示；鼠标移开不会关闭。
- [ ] 固定状态下，点击浮层内部（包括标签删除按钮）不会关闭浮层。
- [ ] 点击浮层和标签区之外的位置后，浮层关闭。
- [ ] 删除单个标签后，浮层和原标签区立即同步更新。
- [ ] 不同记录的浮层内容互相隔离。

### 布局与回归

- [ ] 标签区、「带入 / 复制 / 提交」和「删除」按钮的底边对齐。
- [ ] 「编辑」按钮仍在「删除」按钮上方。
- [ ] 悬浮和固定浮层均不改变卡片高度，不推动其他记录。
- [ ] 原有图片尺寸、位置和模型选择器不变。
- [ ] 原有标签添加、删除、保存及其他记录卡片操作正常。
- [ ] 在不同窗口宽度下，浮层尽可能保持在可视区域内，且不遮挡标签区框。

## 7. 建议实现顺序

1. 调整标签区默认样式：固定高度、隐藏溢出、不显示滚动条。
2. 增加完整标签浮层，并实现左侧定位和必要的视口边界处理。
3. 实现悬浮预览、点击固定、点击外部关闭三种交互状态。
4. 复用现有标签删除逻辑，使浮层与原标签区同步更新。
5. 调整操作行布局，统一标签区、「带入 / 复制 / 提交」和「删除」按钮的底部对齐。
6. 完成不同标签数量、悬浮/固定状态、标签删除和原有卡片功能的回归验证。
