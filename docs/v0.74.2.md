# V0.74.2 需求：统一标签浮层位置与内置清理按钮

- **目标版本**：V0.74.2
- **目标分支**：`feature/v0.74`
- **状态**：需求已确认，待开发
- **文档路径**：`docs/v0.74.2.md`
- **前置版本**：V0.74.1 标签浮层交互与记录卡片按钮对齐
- **范围**：生图管理页面的记录卡片标签区；本次只优化浮层定位/状态和标签清理按钮位置，不改变标签业务逻辑或其他既有功能

## 1. 背景与目标

当前标签区存在两种显示效果：鼠标悬浮时，完整标签浮层显示在标签区左侧；点击标签区固定后，浮层却显示在标签区下方，导致两种状态的位置不一致，并可能占用下方记录卡片的空间。

另外，整体清理按钮目前位于标签区框旁边，占用本可用于标签输入和操作按钮的横向空间。

V0.74.2 需要让悬浮预览与固定状态共用同一左侧浮层和定位规则，并将现有标签清理按钮移入浮层内部。尽量复用已有前端实现，以小范围调整完成，不改变卡片高度、图片尺寸和标签业务行为。

## 2. 统一浮层位置

1. 鼠标悬浮预览和点击固定状态必须使用同一个标签浮层组件/DOM 和同一套定位规则。
2. 浮层统一显示在原标签区框左侧，不允许悬浮时在左侧、固定后切换到下方。
3. 浮层应覆盖显示在原卡片内容上方，不得通过撑开卡片、增加卡片高度或推动其他记录来容纳浮层。
4. 浮层不得遮挡原标签区框。正常情况下优先显示在左侧；若窗口空间不足，应在尽可能保持左侧位置且不遮挡标签区的前提下调整浮层尺寸或位置，并尽量保证其位于可视区域内。
5. 浮层内完整显示当前记录的所有标签，允许多行排列；每个标签继续保留单独删除入口「×」。
6. 不改变浮层内标签的顺序、内容、保存方式或所属记录。

## 3. 浮层交互状态

### 3.1 悬浮预览

- 鼠标移入标签区时，立即显示左侧浮层。
- 鼠标从标签区移入浮层时，浮层保持显示，不能因经过两者之间的区域而闪烁或提前关闭。
- 当浮层未固定，且鼠标同时离开标签区和浮层后，浮层自动关闭。

### 3.2 点击固定

- 点击原标签区框后，将当前显示的左侧浮层切换为固定状态。
- 固定状态下，即使鼠标移出标签区和浮层，浮层仍保持显示。
- 固定状态下，只有点击标签区和浮层之外的位置才关闭浮层。
- 点击浮层内部的标签、单个标签的「×」删除入口以及整体清理按钮，均属于浮层内部交互，不得被误判为点击外部。
- 点击外部关闭后，再次悬浮可恢复临时预览；再次点击标签区可重新固定。

### 3.3 状态一致性

- 悬浮与固定只改变浮层是否保持打开，不改变浮层的定位、尺寸规则或标签内容。
- 同一时刻应正确识别当前正在交互的记录；不得把一个记录的标签显示到另一记录的浮层中。
- 事件处理需避免标签区点击、浮层内部点击和删除按钮的事件冒泡造成误关闭。

## 4. 将整体标签清理按钮移入浮层

1. 将目前位于标签区框旁边的整体标签清理按钮移入左侧完整标签浮层内部。
2. 清理按钮建议放在浮层顶部的独立操作区域（例如右上角），与每个标签自己的「×」删除入口明确区分。
3. 标签区框旁边不再单独占用位置放置该清理按钮，让标签输入区和相邻操作按钮可以使用释放出的横向空间。
4. 清理按钮必须继续执行当前已有的整体清理行为；本次只移动入口位置，不改变清理范围、确认规则、数据持久化或其他业务语义。
5. 每个标签自身的「×」继续用于删除单个标签，两种删除操作不得混淆。
6. 点击整体清理按钮后，标签区和浮层内容应立即同步更新；若清理后没有标签，按现有业务逻辑正确呈现空状态。
7. 清理操作属于浮层内部事件。执行清理时不得因为事件冒泡而立即关闭浮层，除非现有清理逻辑本身明确要求关闭。
8. 不得因为移动按钮而丢失、重复执行或扩大清理操作的影响范围。

## 5. 布局与兼容性约束

- 保持 V0.74.1 已确认的标签区固定高度、默认不显示滚动条、默认紧凑展示等要求。
- 保持标签区、带入/复制/提交和右侧删除按钮的既定底部对齐要求。
- 浮层显示或固定时不改变卡片高度，不推动其他记录。
- 不改变输入图、输出图的尺寸和位置。
- 不修改 Provider、模型选择器、模型验证、生图请求、历史记录、筛选、排序和分页逻辑。
- 标签添加、单标签删除、整体清理、保存及其他记录的标签操作继续复用现有业务逻辑。
- 尽量复用现有浮层实现，不额外创建第二套仅用于固定状态的浮层。

## 6. 验收标准

### 浮层定位与状态

- [ ] 悬浮预览时，浮层显示在标签区左侧。
- [ ] 点击标签区固定后，浮层仍显示在同一左侧位置，不再切换到下方。
- [ ] 悬浮和固定状态共用相同的浮层定位和布局规则。
- [ ] 鼠标可从标签区移动到浮层而不导致预览闪烁或提前关闭。
- [ ] 未固定时，鼠标离开标签区及浮层后浮层关闭。
- [ ] 固定时，鼠标移开不会关闭浮层；点击标签区和浮层之外的位置才关闭。
- [ ] 点击浮层内的标签或操作按钮不会被误判为点击外部。
- [ ] 浮层不遮挡原标签区，不改变卡片高度或推动其他记录。

### 清理按钮

- [ ] 原标签区框旁边不再显示独立的整体清理按钮。
- [ ] 整体清理按钮显示在左侧浮层内部，并与单标签删除入口区分。
- [ ] 整体清理仍执行原有行为，不改变清理范围和业务语义。
- [ ] 单个标签的「×」仍只删除对应标签。
- [ ] 清理或删除后，浮层和原标签区内容即时同步。
- [ ] 执行清理不会因事件冒泡导致浮层意外关闭。

### 回归验证

- [ ] 标签较多时，浮层能完整显示标签且不会出现影响使用的滚动条或裁切。
- [ ] 不同记录的标签浮层互相隔离。
- [ ] 标签添加、单个删除、整体清理及保存功能正常。
- [ ] 带入、复制、提交、编辑、删除等卡片按钮功能不受影响。
- [ ] 模型选择、生图流程、图片尺寸及其他既有功能无回归问题。

## 7. 建议实现顺序

1. 检查 V0.74.1 当前标签浮层的 DOM、状态管理和定位实现，确认固定状态切换到下方的原因。
2. 统一悬浮与固定状态使用的浮层实例及左侧定位逻辑。
3. 整理悬浮、固定、点击外部关闭的状态转换和事件边界。
4. 将现有整体清理按钮移动到浮层内部，保留原有处理函数与业务语义。
5. 移除标签区框旁边为整体清理按钮预留的独立位置，并检查标签输入和相邻按钮的布局。
6. 按验收标准进行交互测试及既有标签、生图和卡片功能回归测试。
