# AI 生图管理软件设计文档

日期：2026-04-30

## 目标

构建一个本地网页软件，用来管理 AI 生成图片和外部收藏的生图案例。软件以“提示词 + 输入图片 + 输出图片 + 标签”为核心，支持文生图、图生图、手动新增实例、搜索筛选、排序、路径批量替换和长期保存。

图片文件本体保留在用户电脑原路径，软件只保存路径和元数据。删除软件实例时，不删除电脑上的图片文件。

## 技术路线

- 前端：HTML + CSS + JavaScript
- 后端：Python + Flask
- 数据库：SQLite
- 配置：JSON
- 生图调用：可插拔 Provider 架构
- 启动方式：双击 CMD 启动本地 Flask 服务并打开浏览器

项目使用标准多文件结构，便于后续扩展和维护。

## 页面结构

应用顶部有两个入口：

- 生图管理
- 设置

“生图管理”是主工作台，包含操作区和保存区。“设置”用于配置全局生成代理商、API 参数和默认生成路径。

## 操作区

操作区位于主页面上方，用于发起文生图或图生图。

包含控件：

- 模式切换：文生图 / 图生图
- 提示词输入
- 输入图片区
- 输出图片区
- 标签编辑
- 生成路径输入
- 生成路径选择按钮
- 生成按钮
- 清空按钮

规则：

- 文生图：提示词必填，输入图片可以为空。
- 图生图：提示词必填，输入图片至少 1 张。
- 每次生成只生成 1 张输出图片。
- 生成路径可以手动粘贴，也可以点击按钮选择目录。
- 生成成功后自动保存为一条实例。
- 自动保存实例继承当前提示词、输入图片、输出图片、标签、生成路径、模式和当前 Provider。
- 生成失败时不创建实例，只显示错误。
- 生成成功后操作区默认保留内容。
- 清空按钮只清空提示词、输入图片和输出图片预览。
- 清空按钮不清空标签、生成路径和当前模式。
- 标签通过标签自己的删除入口移除，便于连续生成时沿用标签。

## 保存区

保存区位于主页面下方，用于长期管理实例。所有实例默认完整显示，不折叠。

每条实例包含：

- 当前结果序号
- 提示词
- 输入图片区：0 张或多张
- 输出图片区：0 或 1 张
- 来源：生成 / 手动
- 模式：文生图 / 图生图 / 未指定
- 日期
- 标签
- 编辑按钮
- 删除按钮

保存区布局：

```text
#001   #002
#003   #004
#005   #006
```

布局规则：

- 序号按当前筛选和排序结果重新显示，不是永久 ID。
- 每行两个实例。
- 同一行两个实例高度保持一致。
- 如果某个实例因输入图片增加而变高，整行同步变高，后面的行整体下移。
- 最后一行如果只有一个实例，右侧留空。
- 不使用瀑布流。
- 每页支持 50 / 100 / 200 条。

## 实例编辑

实例默认只读。点击“编辑”后，实例在原位置进入编辑状态，布局不改变，通过边框颜色和按钮状态区分。

编辑状态允许：

- 修改提示词
- 增加图片
- 删除图片
- 增加标签
- 删除标签

图片位规则：

- 输入图和输出图使用相同样式的图片位。
- 点击某个图片位上的加号，图片就添加到该图片位对应的区域。
- 不弹出“输入图/输出图”的二次选择。
- 输入图片区支持多张图片。
- 输入图片数量超过一行可容纳数量后，自动扩展为两行或更多行。
- 每次扩展增加标准一行高度。
- 输出图片区只有 1 个图片位。
- 输出图可以为空。
- 输出图已有图片时，可以删除后重新添加，或在该位置替换。
- 删除图片只删除数据库中的路径引用，不删除电脑上的图片文件。

保存时更新实例的更新时间。取消编辑时恢复进入编辑前的内容。

## 手动实例

用户可以手动新增实例，用于保存外部看到的提示词、参考图或暂未配图的灵感。

手动实例规则：

- 提示词必填。
- 输入图片可为空或多张。
- 输出图片可为空或 1 张。
- 标签可为空。
- 来源为“手动”。
- 后续可在原位置编辑并补充图片。

## 标签系统

标签为自由输入，不需要预先建立分类。

规则：

- 操作区可以添加标签。
- 保存区实例编辑状态可以添加或删除标签。
- 输入一个不存在的标签时，系统自动创建。
- 从实例删除标签时，只解除该实例和标签的关联。
- 没有任何实例使用的标签可以不显示在筛选列表中。
- 标签筛选使用 AND 逻辑。
- 多个筛选条件组合时也使用 AND 逻辑。

示例：

```text
选中 #产品 和 #海报
只显示同时包含 #产品 和 #海报 的实例
```

## 搜索、筛选和排序

保存区顶部工具栏包含：

- 搜索提示词
- 标签筛选
- 来源筛选
- 日期筛选
- 排序方式
- 每页数量
- 路径批量替换
- 新增实例

搜索和筛选：

- 提示词搜索匹配提示词文本。
- 标签筛选支持多选，使用 AND 逻辑。
- 来源筛选支持全部 / 生成 / 手动。
- 日期筛选支持全部、今天、最近 7 天、最近 30 天和自定义范围。

排序：

- 日期新到旧
- 日期旧到新
- 提示词 A-Z
- 提示词 Z-A

筛选和排序变化后，保存区序号按当前结果重新计算。

## 删除规则

删除实例只删除软件数据库里的记录和关联关系，不删除电脑上的输入图片或输出图片文件。

删除需要二次确认。确认文案：

```text
确认删除这条实例？
这只会删除软件中的记录，不会删除电脑上的图片文件。
```

## 图片路径管理

软件只保存图片路径，不复制手动添加的图片文件。

如果图片原文件移动、删除或路径失效，实例仍保留，但图片位置显示“图片未找到”。

## 路径批量替换

保存区提供“路径批量替换”按钮，用于统一替换数据库中图片路径里的字符。

示例：

```text
查找：C:\old
替换为：D:\new
```

影响范围：

- 输入图片路径
- 输出图片路径

不影响：

- 提示词
- 标签
- 日期
- 来源
- 电脑上的真实图片文件

操作流程：

1. 用户输入查找内容 A 和替换内容 B。
2. 系统预览会影响多少条实例、多少个图片路径。
3. 系统展示若干条修改前和修改后的路径示例。
4. 用户确认后执行替换。
5. 替换前自动备份 SQLite 数据库到 `data/backups/`。

## 设置页

设置页用于管理全局配置。

包含：

- 当前代理商
- API Base URL
- API Key 或 API Key 环境变量名
- 模型名称
- 默认图片尺寸
- 默认生成路径
- 测试连接按钮
- 保存设置按钮

代理商选择是全局配置，不出现在操作区。生成时后端读取当前全局 Provider 设置。

默认生成路径规则：

- 软件启动后，操作区生成路径默认填入设置页的默认生成路径。
- 操作区可以临时修改生成路径。
- 自动保存实例时记录实际使用的生成路径。
- 临时修改操作区路径不会自动覆盖设置页默认路径。
- 只有在设置页保存后才改变默认生成路径。

## Provider 架构

文生图和图生图调用采用可插拔 Provider 架构，便于按代理商切换和扩展。

目录结构：

```text
backend/
  image_providers/
    __init__.py
    base.py
    aiapis_gpt_image_2.py
    provider_config.py
```

每个 Provider 实现统一接口：

```text
text_to_image(prompt, output_dir, options)
image_to_image(prompt, input_images, output_dir, options)
```

第一版接入当前目录已有的文生图和图生图调用方式，整理为 `aiapis_gpt_image_2` Provider。后续新增代理商时，通过新增 Provider 文件和配置扩展，不修改主界面逻辑。

实例保存生成时使用的 Provider 名称：

- 自动生成实例：保存 Provider 名称。
- 手动实例：Provider 为空。

## 数据库设计

SQLite 数据库文件：

```text
data/AIImageManager.data.sqlite
```

建议表：

- `instances`：实例主体信息，包括提示词、来源、模式、输出图路径、生成路径、Provider、创建时间、更新时间。
- `input_images`：实例的输入图片路径，一条实例可对应多条输入图片。
- `tags`：标签字典。
- `instance_tags`：实例和标签的多对多关系。

应用设置保存到 `AIImageManager.config.json`，不放入 SQLite。

提示词搜索可使用 SQLite FTS5 或普通 LIKE 起步。考虑到后期实例会很多，优先设计为可接入 FTS5。

## 第一版范围

第一版实现：

- Flask 本地服务启动和浏览器打开
- 主页面操作区
- 主页面保存区
- 手动新增实例
- 原位置编辑实例
- 删除实例二次确认
- 标签自由输入和 AND 筛选
- 提示词搜索
- 来源、日期筛选
- 排序
- 分页数量 50 / 100 / 200
- 路径批量替换，含预览、确认和数据库备份
- 设置页
- 默认生成路径
- 当前 AIAPIS gpt-image-2 Provider
- 文生图和图生图生成

不在第一版实现：

- 用户账号或云同步
- 复制手动添加图片到统一图库
- 删除真实图片文件
- 瀑布流布局
- 多输出图
- 操作区按次选择 Provider

## 验证重点

- 文生图没有输入图时可以生成。
- 图生图没有输入图时阻止生成并提示。
- 生成成功后自动保存实例。
- 清空按钮不清空标签、生成路径和当前模式。
- 手动实例可以没有输出图。
- 删除实例不删除电脑文件。
- 图片路径失效时实例仍保留。
- 路径批量替换只改数据库路径。
- 标签筛选为 AND。
- 筛选和排序后序号重新计算。
- 保存区每行两个实例且同行等高。
