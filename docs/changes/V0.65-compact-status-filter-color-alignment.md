# V0.65 保存区紧凑化、状态筛选统一和状态颜色强化

## 目标

当前 V0.64 已完成操作区布局细节、实例状态语义、来源筛选改造和复制实例尺寸保留。本版 V0.65 目标是不新增大功能，继续收口生图管理页和历史记录页的状态展示、筛选和空间利用：

- 保存区实例“清标签”按钮改为紧凑的“X”。
- 操作区和保存区实例的 Provider 框、标签框、路径框等控件扩宽，右边更靠近右侧按钮列，但 Provider 标题本身不右移。
- 保存区生成中实例整张卡片改为橙色背景。
- 保存区“准备 / 生成 / 失败”标识使用不同背景色。
- 生图管理页状态筛选统一为“准备 / 生成 / 失败 / 生成中 / 其他”，并删除重复的来源筛选。
- 历史记录页状态筛选统一为“生成 / 失败 / 生成中 / 其他”。
- 保存区实例输入图区“清除”按钮与操作区输入图区“清除”按钮竖直对齐。

本版原则：

- 状态筛选以实例当前状态语义为准，不再用历史来源字段表达。
- 控件扩宽要采用“左边不动、右边扩展”的方式，不能把 Provider 标题整体右移。
- 不改变 V0.64 的准备态、失败态、生成态语义。
- 不改变 V0.64 的复制实例尺寸保留规则。
- 不删除电脑上的图片文件。
- 本文档落成后不直接执行实现，确认后再进入代码修改。

## 保存区实例按钮紧凑化

### 1. “清标签”改为“X”

当前问题：

- 保存区实例有标签时，内联操作区会显示“清标签”按钮。
- “清标签”文字较长，会挤压旁边的“带入 / 复制 / 提交 / 重提”按钮，导致按钮变形或拥挤。

调整方案：

- 将“清标签”按钮文案改为“X”。
- 按钮使用紧凑圆形或胶囊样式。
- 按钮宽度固定，避免挤压其他内联按钮。
- 保留 `title` 或悬停提示，内容为“清除标签”。
- 点击行为不变：仍然清空当前实例的全部标签。

验收标准：

- 有标签实例显示紧凑“X”按钮。
- “带入 / 复制 / 提交 / 重提”按钮不再被“清标签”挤变形。
- 鼠标悬停“X”可以知道它是清除标签。
- 点击“X”仍能清空实例标签。

副作用：

- “X”比“清标签”更省空间，但语义不如文字直观。
- 因此必须保留悬停提示。

## 右侧详情控件扩宽对齐

### 2. Provider 标题不右移，Provider 框向右扩宽

当前要求：

- 操作区和保存区实例的 Provider 标题不要右移。
- 需要右移的是 Provider 标题右边的 Provider 框右边界，也就是把 Provider 框宽度增加一些。
- 同列的标签框、路径框等也按这个逻辑处理。

调整方案：

- 保持操作区 Provider 标题、保存区实例 Provider 标题或 Provider 文案起点不变。
- 扩宽 Provider 框，使其右边更靠近操作区“清空/新增”按钮列或保存区实例“编辑/删除”按钮列。
- 标签框保持左边界不变，右边界向右扩展。
- 路径框保持左边界不变，右边界向右扩展。
- 路径“选择”按钮仍在路径框右侧，并跟随扩展后的右边界靠近按钮列。
- 保存区实例的状态标识、标签框、“提交/重提”按钮区域也按同样规则：左边界不乱动，右边界向右靠近编辑/删除按钮列。
- 详情控件和右侧按钮列之间不保留明显空列，只保留必要的控件间距和网格 gap。

验收标准：

- Provider 标题位置不变。
- Provider 框比当前更宽。
- 标签框比当前更宽。
- 路径框比当前更宽。
- Provider 框、标签框、路径框右边更靠近右侧按钮列。
- 操作区 Provider 框右边与保存区实例状态标识/Provider 行右边竖直规则一致。
- 操作区标签框右边与保存区实例标签框右边竖直规则一致。
- 操作区路径“选择”按钮右边与保存区实例“提交/重提”按钮右边竖直规则一致。
- 不挤压操作区“清空/新增”按钮。
- 不挤压保存区实例“编辑/删除”按钮。

副作用：

- 详情控件右边扩宽后，右侧留白减少，页面会更紧凑。
- 需要检查长 Provider 名称、长路径、多标签、窄窗口下是否仍能正常截断和悬停查看。

## 状态颜色强化

### 3. 生成中实例整卡橙色背景

调整方案：

- 保存区实例处于生成中时，整张实例卡片使用橙色系背景。
- 橙色背景应明显区别于普通准备态背景、生成成功标识和失败标识。
- 生成中读秒、取消/取消中、重试提示必须清晰可读。
- 生成中图片区域、按钮和文本不因背景色改变而对比度不足。

验收标准：

- 生成中实例整卡背景为橙色系。
- 生成中实例一眼可识别。
- 读秒正常显示。
- 取消/取消中按钮正常显示和点击。
- 失败重试提示不被橙色背景淹没。

副作用：

- 生成中橙色会提高视觉权重。
- 需要避免与失败红色混淆。

### 4. “准备 / 生成 / 失败”标识分别上色

调整方案：

- “准备”标识使用一套独立背景色，建议浅蓝或中性浅色。
- “生成”标识使用成功色系，建议浅绿。
- “失败”标识使用失败色系，建议浅红。
- 标识文字和背景要有足够对比度。
- 生成中实例继续用橙色整卡背景和读秒表达，不用“准备 / 生成 / 失败”标识替代读秒。

验收标准：

- 准备、生成、失败三个标识背景色不同。
- 标识颜色和文字都清晰可读。
- 没有输出图的实例不会显示“生成”。
- 失败实例显示“失败”且颜色明显。
- 生成成功实例显示“生成”且颜色明显。

副作用：

- 页面颜色信息增加，需要避免过花。
- 标识颜色应使用低饱和浅色，不抢过图片和主要按钮。

## 生图管理页筛选统一

### 5. 状态筛选改为“准备 / 生成 / 失败 / 生成中 / 其他”

当前问题：

- V0.64 中生图管理页同时存在“状态”和“来源”两个筛选。
- 状态筛选仍偏向数据库原始 `generation_status`，来源筛选表达“生成 / 准备 / 失败”。
- 两者语义重复，容易混淆。

调整方案：

- 生图管理页筛选行保留“状态”筛选。
- 状态筛选下拉项改为：
  - 全部
  - 准备
  - 生成
  - 失败
  - 生成中
  - 其他
- 状态筛选语义：
  - 准备：没有输出图，且不是失败、不是生成中。
  - 生成：有输出图，且不是生成中。
  - 失败：`generation_status === "failed"`。
  - 生成中：`generation_status === "running"`。
  - 其他：不属于以上分类的实例。
- 删除“来源”筛选框。
- 旧 UI 状态中如果还保存了 `source` 筛选值，加载时应清空或忽略，避免隐藏筛选继续生效。

验收标准：

- 生图管理页筛选行不再显示“来源”框。
- 状态下拉显示“全部 / 准备 / 生成 / 失败 / 生成中 / 其他”。
- 选择“准备”只显示准备态实例。
- 选择“生成”只显示有输出图的生成成功实例。
- 选择“失败”只显示失败实例。
- 选择“生成中”只显示生成中实例。
- 旧的来源筛选值不会继续影响列表结果。

副作用：

- 用户不再按“来源”筛选实例，而是按当前状态筛选。
- 这是对 V0.64 状态语义的延续，能避免“来源”和“状态”重复。
- 后端查询层需要和前端下拉语义一致，否则筛选结果会不准。

## 历史记录页状态筛选

### 6. 历史记录状态筛选改为“生成 / 失败 / 生成中 / 其他”

当前情况：

- 历史记录没有准备态记录。
- 历史记录内部状态为 `success / failed / running / other`。

调整方案：

- 历史记录页状态筛选下拉项改为：
  - 全部
  - 生成
  - 失败
  - 生成中
  - 其他
- 显示映射：
  - `success` 显示为“生成”。
  - `failed` 显示为“失败”。
  - `running` 显示为“生成中”。
  - `other` 显示为“其他”。
- 不增加“准备”选项。
- 后端历史记录筛选仍可使用原内部值，但前端显示必须统一中文语义。

验收标准：

- 历史记录状态下拉没有“准备”。
- 历史记录状态下拉显示“全部 / 生成 / 失败 / 生成中 / 其他”。
- 选择“生成”能筛选成功历史。
- 选择“失败”能筛选失败历史。
- 选择“生成中”能筛选运行中历史。
- 历史记录卡片状态标识也使用同样中文显示。

副作用：

- 历史记录内部值仍是 `success`，但 UI 显示为“生成”。
- 需要避免导出、备份、恢复中误改历史状态原始值。

## 输入图清除按钮对齐

### 7. 保存区和操作区输入图“清除”按钮竖直对齐

调整方案：

- 保存区实例输入图区的“清除”按钮与操作区输入图区的“清除”按钮竖直对齐。
- 对齐应基于输入图区标题行和右边界，而不是手工偏移。
- 该规则要兼容 V0.64 中输入图区和尺寸控制区的列宽调整。

验收标准：

- 操作区输入图“清除”按钮和保存区实例输入图“清除”按钮左右位置一致。
- 单列模式下对齐稳定。
- 双列模式下保存区实例内部不破版。
- 操作区输入图区变宽后，清除按钮仍在正确位置。

副作用：

- 输入图区标题行的内部布局可能需要统一。
- 需要检查“清除”按钮在没有输入图、多个输入图、编辑态和只读态下的显示。
