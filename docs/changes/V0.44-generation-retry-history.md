# V0.44 生成重试与历史明细

## 目标

V0.44 针对 AIAPIS / Cloudflare 间歇性 502、503、504、429、连接超时、读取超时等可重试错误做稳定性增强。目标不是保证外部服务器永远正常，而是让这类可重试错误不再直接导致本次生成失败：软件会自动等待并重试，直到生成成功、遇到不可重试错误，或用户手动取消。

## 已讨论结论

- 502 Bad gateway、timeout、Cloudflare retryable 等错误属于可重试错误。
- 可重试错误不再立即标记最终失败。
- 每一次失败重试都必须写入历史记录，保留失败原因、尝试次数、等待秒数。
- 最终生成成功后，主历史记录仍显示成功；中间失败重试作为额外失败历史记录保留。
- 自定义代码默认不做无限自动重试，避免自由脚本重复执行产生不可控副作用。
- 固定 OpenAI 调用示例由后端统一重试，不在脚本内部长时间 sleep，避免脚本执行超时后前端无法取消或显示进度。

## 变更内容

### 1. 后端生成自动重试

`/api/generate` 增加可重试错误识别和重试循环。

可重试范围包括：

- HTTP 429
- HTTP 502
- HTTP 503
- HTTP 504
- ConnectTimeout / ReadTimeout / APITimeoutError
- Connection error / connection reset
- Cloudflare 返回的 retryable=true
- Bad gateway / origin_bad_gateway / gateway timeout / service unavailable

重试等待规则：

- 如果错误中包含 retry_after，则优先按 retry_after 等待。
- 否则按 10 秒、30 秒、60 秒、120 秒递增等待，之后保持较长等待。
- 默认持续重试，直到成功或用户取消。

### 2. 历史记录记录每次失败重试

每次可重试失败都会新增一条历史记录：

- status = failed
- error_message 记录失败原因
- params 中记录 retry_attempt
- params 中记录 retry_delay_seconds
- params 中记录 retryable = true
- params 中记录 parent_history_id，指向本次生成的主历史记录

最终成功时，主历史记录更新为 success，并记录最终输出路径。这样历史页可以同时看到：

- 第 1 次失败，等待重试
- 第 2 次失败，等待重试
- 最终成功记录

### 3. 生成中实例保留并显示重试状态

保存区生成中实例继续保持唯一，不新增重复实例。

当进入重试等待时：

- 实例仍显示在过程区
- 输出图区显示读秒
- 文案显示“重试中 + 失败原因摘要”
- 成功后原实例更新为正常输出图

### 4. 增加取消生成

生成中实例增加取消按钮。

如果服务器长时间不可用，用户可以取消等待。取消后：

- 后端停止后续重试
- 当前实例按失败/取消状态处理
- 不删除电脑上的图片文件

### 5. 共享 OpenAI 脚本与后端重试边界

`files/openai_text_to_image.py` 和 `files/openai_image_to_image.py` 继续作为软件固定调用示例和实际生成脚本：

- 脚本只负责一次实际 OpenAI 请求和图片落盘。
- 脚本输出 result_json，包含 output_paths 和可选 retry_events。
- 自动重试由后端 `/api/generate` 统一控制。
- 每次后端捕获到脚本中的 502、503、504、429、timeout 等可重试错误，就写入一条失败历史记录，然后等待重试。
- 本地回环地址 `127.0.0.1` / `localhost` 不走系统代理，避免 mock 测试或本地服务被代理劫持；真实 AIAPIS 地址仍按现有代理规则执行。

## 不做内容

- 不改 Provider 结构
- 不改数据库 schema
- 不改备份/导出/恢复格式
- 不对自定义代码做默认无限自动重试
- 不新增多 Provider 自动切换

## 副作用与风险

- 自动重试可能增加 API 调用次数和费用。
- 如果服务端实际已经收到请求但返回 502，再重试可能生成多次；软件只保存最终成功返回的文件。
- 如果服务器持续不可用，任务会长时间停留在重试中，直到用户取消。
- API key 错误、余额不足、权限错误、内容被拒、输出目录不可写等不可重试问题仍会失败。
- 自由填写的自定义代码不默认无限重试，所以自定义脚本里的 502 仍需要用户自己处理；软件固定 OpenAI 调用示例走后端统一重试。

## 验收重点

- Mock 502 -> success 时，`/api/generate` 最终返回 201。
- 保存区最终实例是 ready，输出图存在。
- 历史记录包含每次失败重试记录。
- 最终成功历史记录仍为 success。
- 共享脚本 result_json 支持 output_paths 和可选 retry_events。
- 前端生成中状态能显示重试原因和读秒。
- 取消生成接口可用。
