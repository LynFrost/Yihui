## 输入与下拉稳定性

修复这些现象：

```text
操作区和保存区实例点击后闪一下，无法输入文字。
来源筛选、排序、每页数量等 select 点击后一闪就消失，无法驻停操作。
```

根因处理：

- 不要在普通输入控件点击时触发批量保存后重绘页面。
- `textarea`、`input`、`select`、`button`、标签下拉、尺寸下拉、图片弹窗、路径替换弹窗、显示方式下拉点击时，跳过批量保存。
- 批量保存只在用户从一个保存区实例切换到另一个保存区实例，或点击保存区实例外的明确空白区域时触发。
- 批量保存完成后，不得抢走当前用户点击目标的焦点。
- 批量保存失败时，失败实例保留编辑状态，顶部显示错误，不阻止当前目标继续获得焦点。

实现建议：

- 将 V0.04 在 `app` 上的全局 `click` 批量保存逻辑拆成独立判断函数。
- 用 `isInteractiveTarget(event.target)` 判断输入控件、按钮、下拉菜单、弹窗等交互目标。
- 对交互目标直接跳过批量保存。
- 如果需要保存，使用 `queueMicrotask()` 或 `setTimeout(..., 0)` 延后，不要在目标控件默认交互之前同步 `renderManager()`。

## 操作区布局

生成路径框下边缘必须与输入图框下边缘对齐。

规则：

- 操作区 `record-detail` 使用固定纵向布局：

```text
Provider 文本
标签输入框
生成路径框
```

- `record-detail` 高度与输入图区主高度一致。
- 生成路径框贴近 `record-detail` 底部。
- 输入图区为空或文生图占位时，也保持同样底部基线。

文生图模式：

- 不显示输入图标题、边框或加号。
- 提示词框继续加宽。
- 提示词框跨过原输入图区可用空间。
- 尺寸选框被推到紧挨输出图左侧。
- 输出图、标签区、生成路径、清空/生成按钮的位置保持与图生图模式一致。
- 页面不能出现横向溢出。

图生图模式：

- 维持当前输入图区、输出图、标签区、生成路径、按钮列的固定位置。
- 输入图区一行容量保持 V0.04 的规则。

## 标签清空 X

标签筛选：

- 清空 X 放在标签筛选框内部最右侧。
- 不放在标签筛选框外部右边。
- X 的功能是清空当前已选择的所有筛选 TAG。
- 没有已选 TAG 时，X 隐藏或禁用。

操作区添加标签框：

- 添加标签框内部最右侧增加 X。
- X 的功能是清空操作区当前已添加的所有 TAG。
- 不清空提示词、输入图、输出图、尺寸、生成路径。
- 没有已添加 TAG 时，X 隐藏或禁用。

保存区实例添加标签框：

- 添加标签框内部最右侧增加 X。
- X 的功能是清空该实例当前草稿中的所有 TAG。
- 不清空提示词、输入图、输出图、provider。
- 没有已添加 TAG 时，X 隐藏或禁用。

实现规则：

- X 是标签输入容器内部元素，使用绝对定位或容器内尾部按钮。
- TAG chip 和输入框不能被 X 遮挡。
- X 点击时不触发批量保存。

## 保存区来源与 Provider

保存区实例左侧编号下面不再显示：

```text
手动保存
自动生成
生成
```

来源移动到 provider 区域右侧。

显示格式：

自动生成实例：

```text
Provider：AIAPIS GPT Image 2    自动生成
```

手动保存实例：

```text
Provider：未填写    手动保存
```

样式：

- Provider 文本使用普通小字。
- 来源文字使用更弱的徽标样式，例如浅灰底小标签。
- Provider 和来源在同一行。
- 自动生成和手动保存的来源样式保持一致，只是文字不同。

编辑规则：

- 自动生成实例的 provider 只读，不允许修改。
- 手动保存实例进入编辑模式后，provider 可手动添加或修改。
- 手动 provider 使用自由输入。
- 输入框提供已有 provider 候选。
- 候选来自 `settings.providers` 的 key 和 `display_name`。
- 保存时写入实例现有 `provider` 字段。
- 不新增数据库字段。

后端规则：

- `provider` 字段继续允许任意字符串或空值。
- `update_instance()` 保存手动 provider 字符串。
- `hydrate_instance()` 返回原 provider 字段即可。

前端显示规则：

- 如果 provider 值能匹配 `settings.providers` 的 key，显示其 `display_name`。
- 如果不能匹配，直接显示 provider 原文。
- 如果为空，显示 `未填写`。

## 显示方式控件

保存区“显示方式”改成和“来源筛选 / 排序 / 每页数量”一样的下拉选择。

规则：

- 标题“显示方式”和“来源筛选 / 排序 / 每页数量”水平对齐。
- 控件使用 `select name="save_layout"`。
- 选项：

```text
双列
单列
```

- 切换后立即保存到 `settings.save_layout`。
- 切换后刷新保存区布局。
- 删除 V0.04 的两个并排按钮式 `layout-toggle`。
- 不再存在单列/双列按钮高亮不明显的问题。

## 保存区总数与翻页位置

总数和翻页移动到保存区实例上方。

结构顺序：

```text
筛选工具栏
总数 / 第 N / M 页 / 上一页 / 下一页
保存区实例列表
```

规则：

- 底部不再显示总数和翻页。
- 单列和双列都使用同一套顶部分页行。
- 顶部分页行与筛选工具栏有清晰间距。
- 页面宽度较小时，分页按钮不能溢出。

## 背景颜色

画布、操作区、保存区实例使用不同浅色。

建议色值：

```css
--bg: #eef2f6;             /* 页面画布 */
--operation-bg: #f3f8ff;   /* 操作区 */
--instance-bg: #f7fbf4;    /* 保存区实例 */
```

规则：

- 操作区背景使用 `--operation-bg`。
- 保存区实例背景使用 `--instance-bg`。
- 普通面板、工具栏仍可使用白色或接近白色。
- 边框继续保持 V0.04 的较深边框，确保区域清楚。
- 不使用高饱和颜色，不使用渐变。

## 提示词完整显示与输入

保留 V0.04 的浮层完整显示能力，但修复输入不可用问题。

规则：

- 操作区提示词可以点击并输入。
- 保存区编辑态提示词可以点击并输入。
- 保存区非编辑态提示词悬停显示完整内容。
- 输入时浮层同步显示当前内容。
- 浮层 `pointer-events: none`。
- 浮层不得触发批量保存或导致控件重绘。
- 真实 textarea 始终可获得焦点。
