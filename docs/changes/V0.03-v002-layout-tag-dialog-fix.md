文档版本：V0.03

日期：2026-05-01

## 版本目录

以 `AI生图软件/软件版本_V0.02/` 为基础，完整复制为：

```text
AI生图软件/软件版本_V0.03/
```

共享目录继续放在 `AI生图软件/` 下：

```text
AI生图软件/data/

AI生图软件/docs/
AI生图软件/generated/
```

V0.03 只修改 `AI生图软件/软件版本_V0.03/` 下的软件代码，以及本文件。不要修改 V0.01 和 V0.02 版本目录。

`AI生图软件/软件版本_V0.03/VERSION` 写入：

```text

```

## 配置字段

配置文件继续放在：

```text
AI生图软件/config/AIImageManager.config.json
```

新增或继续使用这些全局配置：

```json
{
  "default_size": "1024x1024",
  "default_output_dir": "D:/AIOutput",
  "save_layout": "double"
}
```

字段规则：

- `default_size` 是操作区生成尺寸默认值。
- `default_output_dir` 是操作区生成路径默认值。
- `save_layout` 是保存区显示方式，值只能是 `single` 或 `double`。
- 缺失 `save_layout` 时默认使用 `double`。

## 设置页与 API Key

设置页删除这些控件：

```text
default_size
default_output_dir
清除 API Key
```

API Key 输入框直接显示真实值：

- 不再使用 `********` 掩码。
- 不再使用 `__CLEAR_API_KEY__`。
- 不再保留“清除 API Key”勾选框。
- 输入框里是什么，保存后配置文件就写入什么。
- 输入框清空后保存，就是清空本地配置里的 API Key。

后端设置接口同步简化：

- `GET /api/settings` 返回真实 API Key。
- `PUT /api/settings` 直接保存提交的 API Key。
- 删除 `public_config()` 中的 API Key 掩码逻辑。
- 删除 `preserve_masked_api_keys()` 和相关测试。
- 删除 `API_KEY_MASK`、`API_KEY_CLEAR_SENTINEL` 相关逻辑。

保留 `api_key_env`：

- 如果 API Key 输入框为空，但配置了 `api_key_env`，生成提供方仍可从环境变量读取。

## 默认生成路径

设置页不再显示默认生成路径。

操作区生成路径作为全局默认路径管理：

- 页面启动时，从 `settings.default_output_dir` 初始化操作区生成路径。
- 点击操作区生成路径的“选择”按钮后，将选中的路径写入 `state.operation.generation_path`。
- 同步保存到配置文件 `settings.default_output_dir`。
- 后续刷新页面、重启软件，都沿用这个路径。
- 再次选择新路径后，用新路径覆盖旧路径。

清空操作区时：

- 不清空生成路径。
- 不清空标签。
- 不清空尺寸。

## 操作区布局

操作区继续保持横向紧凑布局。

操作区显示当前 provider：

- 读取 `settings.active_provider`。
- 使用 provider 的 `display_name`，没有则显示 provider key。
- Provider 小字放在添加标签控件上方。
- 添加标签控件整体下移，给 provider 文本留位置。

文生图模式：

- 不显示输入图区。
- 布局包含：模式、提示词、尺寸、输出图、标签/路径、操作按钮。
- 提示词区域使用输入图区释放出来的空间。

图生图模式：

- 显示输入图区。
- 输入图区宽度比 V0.02 减少约一半。
- 一行约容纳 6 张输入图。
- 减少出来的宽度加到提示词框。

尺寸按钮：

- 修复 `1024x1024` 显示被遮挡的问题。
- 尺寸按钮列宽必须能完整显示 `1024x1024`。
- 尺寸按钮文字不换行、不截断。

## 保存区显示方式

保存区新增显示方式切换：

```text
单列显示 / 双列显示
```

交互规则：

- 使用分段按钮或 select 控件。
- 当前值来自 `settings.save_layout`。
- 切换后立即刷新保存区布局。
- 切换后同步保存到配置文件。
- 下次打开软件沿用上次选择。

双列显示：

- 一行两个实例。
- 新增实例按钮一次新增 2 条手动实例。
- 两条新实例都进入编辑模式。
- 这样可以保持左右列稳定，不因为只新增 1 条导致后续实例换列。

单列显示：

- 一行一个实例。
- 新增实例按钮一次新增 1 条手动实例。
- 实例宽度占满保存区。
- 提示词、输入图区、输出图、路径区域宽度按单列重新分配，整体接近操作区宽度。

## 保存区实例对齐

生成路径框和按钮必须对齐。

实例布局拆成固定区域：

```text
第一行：元信息 / 提示词 / 输入图区第一行 / 输出图 / 路径与编辑按钮
第二行及以后：只给输入图区扩展使用，可横跨右侧空白区域
```

按钮规则：

- 编辑按钮位置固定在路径区域右侧或上方固定位置。
- 删除按钮位置固定在右下区域。
- 输入图区增高时，编辑和删除按钮不跟着向下漂移。
- 生成路径输入框和编辑按钮保持同一视觉基线。
- 删除按钮和生成路径区域保持固定对齐关系。

输入图区换行规则：

- 真实图片数量能放在一行时，实例高度回归一行。
- 编辑状态下的添加图片 `+` 不得单独撑出空白第二行。
- 点击保存或取消退出编辑后，如果只有 3 张图片，去掉空的第二行。
- 第二行及更多行可以使用输出图、路径框、按钮下方的横向空间。
- 除输入图片区增加行高外，其他区域的位置和尺寸保持不变。

## 图片添加和路径选择窗口

修复文件选择报错：

```text
无法打开文件选择窗口：main thread is not in main loop
```

不要继续在 Flask 请求线程中反复创建 Tkinter 主循环。

改用独立 Windows 原生选择进程：

- 图片选择使用 PowerShell + `System.Windows.Forms.OpenFileDialog`。
- 文件夹选择使用 PowerShell + `System.Windows.Forms.FolderBrowserDialog`。
- 每次选择都启动独立进程，选择结束后进程退出。
- 不复用 Tk 根窗口。
- 不依赖 Tk main loop。

接口保持不变：

```text
POST /api/dialogs/images
POST /api/dialogs/directory
```

返回格式保持不变：

```json
{"paths": ["D:/Images/a.png"]}
{"path": "D:/AIOutput"}
```

错误处理：

- 用户取消选择时返回空路径或空列表，不显示错误。
- 选择进程异常时返回 JSON 错误。
- 前端只在真实异常时显示错误。

## 标签选择控件

操作区和保存区编辑状态都使用同一套标签选择控件。

标签来源：

```text
GET /api/tags
```

控件结构：

- 一个输入/显示容器。
- 已添加 TAG 以 chip 形式显示在容器内部。
- 容器内保留一个输入框，用于搜索已有 TAG 或输入新 TAG。
- 下拉列表显示当前已有 TAG。
- 下拉列表提供“新加”选项。

已有 TAG：

- 输入文字时过滤已有 TAG。
- 点击已有 TAG 后加入当前实例或操作区。
- 已经加入的 TAG 不重复加入。

新加 TAG：

- 当输入内容不为空，且不在已有 TAG 中时，显示：

```text
新加：xxx
```

- 点击“新加：xxx”后，将该文字作为新 TAG 加入。
- 按 Enter 时，如果有精确匹配的已有 TAG，优先加入已有 TAG；否则新加当前输入内容。

已添加 TAG 显示：

- TAG chip 显示在“添加标签”容器内部。
- chip 旁边保留删除按钮。
- 超过一行时，容器高度自然增加。
- 两行时高度约为一行的 2 倍，三行时继续增加。
- 不再单独在下方显示一块独立 tag-list 占空间。

保存区编辑状态：

- 点击编辑后，标签控件显示已有 TAG 可选。
- 可以新加 TAG。
- 保存后写入实例标签。

操作区：

- 生成前可以选择已有 TAG 或新加 TAG。
- 生成后实例继承操作区当前 TAG。

## 提示词清空按钮

操作区提示词框内部增加清空按钮：

```text
X
```

规则：

- 鼠标悬停到提示词区域时显示。
- 鼠标移开时隐藏。
- 点击后清空操作区提示词。
- 只影响操作区提示词。
- 不清空标签、路径、尺寸、输入图、输出图。

保存区实例暂不增加清空按钮。

## 提示词临时展开

所有提示词框在输入、聚焦或悬停时，可以临时展开显示完整内容。

适用范围：

- 操作区提示词。
- 保存区编辑状态提示词。
- 保存区非编辑状态提示词悬停。

实现方式：

- 使用浮层覆盖方式显示完整内容。
- 原实例和操作区整体高度不变。
- 浮层可以暂时遮住旁边内容。
- 鼠标移开或失焦后，浮层消失。
- 原提示词框高度恢复固定高度。

展开规则：

- 浮层宽度与原提示词框一致。
- 浮层最小高度等于原提示词框高度。
- 浮层高度按内容自然增加。
- 浮层内不出现滚动条，尽量显示完整文本。
- 文本为空时不显示浮层。
- 编辑状态下在浮层或原 textarea 中输入，内容同步到同一个字段。

## 总数和分页

保存区底部将总数和分页放到同一行。

显示格式：

```text
总数 7    第 1 / 1 页    上一页 下一页
```

规则：

- 左侧显示总数。
- 中间显示页码。
- 右侧显示上一页/下一页按钮。
- 单列和双列显示都使用同一套底部栏。

删除独立左下角的总数行。

## 后端批量新增实例

新增接口或扩展现有新增逻辑，用于一次创建多条手动实例。

推荐新增接口：

```text
POST /api/instances/bulk
```

请求：

```json
{
  "items": [
    {"prompt": "新实例", "source": "manual"},
    {"prompt": "新实例", "source": "manual"}
  ]
}
```

返回：

```json
{
  "items": [...]
}
```

前端规则：

- `save_layout === "double"` 时，点击新增实例调用批量新增 2 条。
- `save_layout === "single"` 时，点击新增实例新增 1 条。
- 新增后清空当前筛选，回到第一页，新增实例进入编辑模式。
