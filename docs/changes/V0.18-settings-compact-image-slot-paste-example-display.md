## 顶部标题固定

`AI 生图管理` 顶部标题区固定在页面顶端。

实现规则：

- 顶部 `app-header` 使用 `position: sticky`。
- `top: 0`。
- 设置足够高的 `z-index`，确保页面滚动时标题区不被内容盖住。
- 大图弹窗、悬停预览、下拉菜单的层级必须高于或合理避开顶部栏，不能被顶部栏遮挡。
- 页面主体不额外增加明显空白，保持当前内容从标题下方自然开始。

## 图片位选中与上传按钮分离

所有可以选择图片路径的位置，空图片位拆成：

```text
图片区容器
  + 独立加号按钮
```

支持位置：

- 操作区输入图空图片位。
- 操作区输出图空图片位。
- 保存区实例编辑状态下的输入图空图片位。
- 保存区实例编辑状态下的输出图空图片位。

交互规则：

- 点击空图片位里的 `+` 按钮，打开原有文件选择窗口。
- 点击空图片位的 `+` 按钮以外区域，只选中该图片位。
- 选中空图片位后，可以从 Windows 资源管理器复制图片文件，再回到软件按 `Ctrl+V` 粘贴原始绝对路径。
- 粘贴逻辑继续使用 V0.17 的 `/api/clipboard/image-paths`。
- 软件继续只记录原始本地绝对路径，不复制图片，不改名图片。
- 空图片位不打开大图。
- 已有图片位点击图片仍打开大图。
- 已有图片位不承担粘贴替换；如果需要替换图片，先删除图片，让该位置回到空图片位，再选中并粘贴或点击 `+` 选择。
- 拖拽图片仍不导入，只提示：`拖拽无法读取原始路径，请从资源管理器复制图片文件后粘贴，或点击选择图片。`

样式规则：

- `+` 按钮要足够明确，避免用户误以为点击空图片位任意位置都会打开文件选择窗口。
- 空图片位选中状态保留 V0.17 的高亮轮廓，或使用同等清晰的选中样式。
- 选中样式不得改变图片位尺寸，不得导致操作区或保存区实例布局跳动。
- 已有图片位的悬停路径、删除按钮、替换按钮显示规则保持不变。

## 调用示例默认显示

调用示例内容必须默认直接显示，不需要点击 `编辑` 才显示。

根因处理：

- 不再让空白的自定义代码面板或旧的 active tab 状态导致固定示例区域看起来为空。
- 渲染设置页时，如果当前页签是 `自定义代码`，但自定义代码为空，则默认显示 `调用示例` 页签。
- 固定示例 textarea 永远在 `调用示例` 页签中直接渲染内容。
- `编辑` 只控制是否可编辑，不控制是否显示。
- 点击 `编辑` 后，按钮必须有明显高亮状态。

保留的标题行：

```text
调用示例  自定义代码                                      编辑  保存  取消  复制
```

去掉的内容：

- 去掉调用示例分组框外层单独的 `调用示例` 标题行。
- 不去掉 `调用示例 / 自定义代码 / 编辑 / 保存 / 取消 / 复制` 这一行。

实现规则：

- `OpenAI API 参数` 后面直接显示代码示例区域，不再额外显示一个带标题的 `调用示例` 分组框标题。
- 代码示例区域仍保留边框、背景、内边距和层次，不能和上一个参数框粘在一起。
- `调用示例` 页签默认显示固定示例。
- `自定义代码` 页签只有在用户点击时切换。
- 如果自定义代码非空，仍显示醒目提示：`当前自定义代码已启用，生成将使用自定义代码。`
- 代码框根据内容自动增高，不出现纵向滚动条。
- 长行自动换行，不横向撑破页面。

## 设置页 Provider 信息压缩

去掉 `Provider 基础信息` 标题，节省纵向空间。

第一行字段顺序调整为：

```text
显示名称    内部编号    接口类型
```

实现规则：

- `显示名称` 放在 `内部编号` 前面。
- `接口类型` 和它的下拉框放到 `内部编号` 右边。
- `接口类型` 的字体、标题样式、输入框高度与 `显示名称`、`内部编号` 保持一致。
- 删除原来单独的 `接口类型` 分组框。
- `内部编号` 在已有 Provider 中继续只读；新建 Provider 时继续可编辑。
- `接口类型` 仍可选：

```text
openai
google
other
```

- `Provider` 顶部选择框和 `新建 Provider / 保存设置 / 删除 Provider` 按钮保持在设置页标题行。

窄屏规则：

- 宽度不足时，`显示名称`、`内部编号`、`接口类型` 自动换行排列。
- 不允许设置页出现横向滚动。

## 连接信息压缩

`连接信息` 分组内部改为两行布局：

```text
base_url     api_key
api_key_env  user_agent
```

实现规则：

- `base_url` 和 `api_key` 同一行。
- `api_key_env` 和 `user_agent` 同一行。
- 每个字段保持当前输入框样式。
- `api_key` 继续原样显示，不做密码隐藏。
- `api_key_env` 标题右侧继续显示简短说明：

```text
填写 api_key 时优先使用 api_key；api_key 为空时使用 api_key_env。
```

- 说明文字不得把输入框挤压到不可用。
- 窄屏时自动变为单列。

示例：


## 副作用处理

空图片位把“选中”和“上传”拆开后，误触文件选择窗口的概率会降低；代价是用户必须点中 `+` 按钮才会打开文件选择窗口。

已有图片点击仍打开大图，因此不能直接粘贴替换已有图片。替换流程固定为先删除图片，再选中空图片位粘贴或点击 `+` 选择。

顶部标题固定后，页面滚动时可见面积会略少。必须保证弹窗、下拉菜单、悬停预览的层级和定位不被顶部栏破坏。

设置页压缩后信息密度更高。窄屏时必须自动换行，不能为了同行布局造成横向溢出。

去掉外层 `调用示例` 标题后，调用示例区域会更紧凑。需要保留代码区域自身边框和背景，避免和上一个参数区域混在一起。

浏览器缓存和旧服务占用端口都可能造成用户看到旧界面。V0.18 通过静态文件版本查询参数降低缓存风险；启动脚本只提示已有服务风险，不自动关闭旧服务。
