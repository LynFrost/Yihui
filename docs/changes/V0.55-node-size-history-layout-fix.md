# V0.55 节点下拉、尺寸排序与历史筛选布局修复

## 目标

当前 V0.54 已完成历史浮窗、节点下拉、尺寸显示和历史标签筛选的收口，但实际使用中仍有几项没有完全达到预期。本版 V0.55 不新增大功能，重点修复 V0.54 未完全封闭的交互和布局问题。

本版原则：

- 不新增数据库 schema。
- 不改变生成、保存、历史记录写入流程。
- 不改变 Provider 能力体系。
- 不改变 V0.52/V0.53/V0.54 已确定的筛选字段和编号规则。
- 不删除电脑上的图片文件。
- 尺寸前缀 `1K / 2K / 4K` 继续只通过软件固定映射表判断，不通过宽高反推。
- 文档确认后再执行实现；本文档落成不等于直接开始改代码。

## 修改项

### 1. 修复节点下拉点击外部不关闭

当前问题：

- 生图管理页中，节点下拉框打开后，点击下拉框以外仍然没有稳定关闭。
- V0.54 已有相关逻辑，但实际页面效果未达到要求，因此 V0.55 必须按页面行为重新排查和封闭。

调整方案：

- 节点下拉打开后，点击以下区域时必须关闭节点下拉：
  - 保存区空白区域。
  - 筛选栏区域。
  - 批量工具栏区域。
  - 实例卡片区域。
  - 页面其他非节点区域。
- 点击以下区域时不关闭节点下拉：
  - 当前节点下拉框内部。
  - 节点下拉触发按钮/选择框。
  - 节点右键菜单内部。
  - 节点新建/重命名弹窗内部。
- 如果节点右键菜单已经打开：
  - 点击节点下拉或右键菜单外部时，同时关闭节点下拉和右键菜单。
  - 点击右键菜单内部时，不误关闭。
- 检查事件监听顺序，避免出现“先关闭又被重新打开”或“点击外部没有触发关闭”的情况。
- 修复完成后必须用页面操作复现验证，不能只看代码逻辑。

验收标准：

- 打开任意层级节点下拉后，点击外部区域，下拉立即关闭。
- 打开节点右键菜单后，节点下拉保持打开。
- 右键菜单出现时，点击外部能同时关闭右键菜单和节点下拉。
- 点击右键菜单内部的“重命名”“删除”不被外部关闭逻辑打断。
- 节点筛选、进入子节点、返回上级、“全部 / 其他 / 新建 / 用户节点”逻辑不回退。

### 2. 生图管理页尺寸筛选按 1K / 2K / 4K 分组排序

当前需求：

- 生图管理页筛选行的尺寸下拉框中，尺寸排序按照 `1K / 2K / 4K` 分别排在一起。

调整方案：

- 尺寸筛选选项显示仍沿用 V0.54 的显示规则：
  - 固定映射表命中的尺寸显示为 `1K：1024x1024` 这类格式。
  - 自定义尺寸或固定映射表未命中的尺寸只显示原始尺寸，例如 `123x123`。
- 排序规则调整为：
  - `全部` 固定在最前。
  - `未记录` 放在基础选项前部。
  - 固定映射表中的 `1K` 尺寸排成一组。
  - 固定映射表中的 `2K` 尺寸排成一组。
  - 固定映射表中的 `4K` 尺寸排成一组。
  - 其他自定义尺寸排在最后。
- 同一组内按照固定映射表的顺序排序，避免每次刷新顺序跳动。
- 排序只影响下拉显示顺序，不改变筛选提交值。

验收标准：

- 生图管理页尺寸下拉中，`1K` 尺寸集中在一起，`2K` 尺寸集中在一起，`4K` 尺寸集中在一起。
- 自定义尺寸不被误归入 `1K / 2K / 4K`。
- 选择任意尺寸后，后端查询仍按原始尺寸值筛选。
- 保存区分页、搜索、标签、状态、Provider、模式、调用方式、model、来源筛选不回退。

### 3. 历史记录页尺寸筛选按 1K / 2K / 4K 分组排序

当前需求：

- 历史记录页筛选行的尺寸下拉框中，尺寸排序也要按照 `1K / 2K / 4K` 分别排在一起。

调整方案：

- 历史记录页复用与生图管理页一致的尺寸显示和排序规则。
- 固定映射表命中的尺寸显示前缀。
- 自定义尺寸不加前缀。
- 排序只影响下拉展示，不改变历史记录查询参数。

验收标准：

- 历史记录页尺寸下拉中，`1K / 2K / 4K` 各自成组。
- 历史记录卡片里的尺寸显示继续符合 V0.54 规则。
- 历史记录筛选仍走后端查询。
- 历史记录搜索、标签、状态、Provider、模式、调用方式、model、日期筛选不回退。

### 4. 历史记录页标签筛选框加宽

当前需求：

- 历史记录页筛选行的标签框需要改宽一点。
- 宽度可以和生图管理页筛选行的标签框一致。

调整方案：

- 历史记录页标签筛选框宽度对齐生图管理页标签筛选框。
- 标签框仍保持 V0.54 的多选、清除、虚拟“无”、搜索 TAG 逻辑。
- 多选标签较多时，优先让标签框内部正常展示，不挤压日期输入框。
- 空间不足时允许筛选行自然换行，不允许把开始日期挤到显示不完整。

验收标准：

- 历史记录页标签筛选框明显变宽，并与生图管理页标签筛选框宽度保持一致。
- 多选标签时显示不拥挤。
- 标签筛选下拉、多选、清除、“无”虚拟项逻辑不回退。
- 旧历史缺少 TAG 快照时仍可归入“无”，不报错。

### 5. 历史记录页开始日期完整显示

当前问题：

- 历史记录页中，开始日期仍然被挤占，没有完整显示。

调整方案：

- 调整历史页日期行布局：
  - 开始日期框必须完整显示。
  - 结束日期框整体向右让出空间。
  - 每页数量、总数、首页、上一页、下一页、尾页继续保持在右侧分页工具组。
- 当窗口宽度不足时：
  - 优先保证开始日期和结束日期完整显示。
  - 允许分页工具组换到下一行。
  - 不允许日期框被压缩到内容显示不全。
- 不通过缩小日期文字或隐藏字段来解决。

验收标准：

- 开始日期完整显示。
- 结束日期完整显示。
- 每页数量仍在总数左边挨着。
- 总数、首页、上一页、下一页、尾页仍可正常操作。
- 日期筛选变化后历史记录能立即刷新。

## 副作用与处理

- 节点下拉外部点击关闭如果事件边界过宽，可能误关右键菜单或节点弹窗，因此必须明确保留节点下拉内部、右键菜单内部、节点弹窗内部为例外区域。
- 节点下拉关闭逻辑如果放在错误的事件阶段，可能出现点击外部无效或刚关闭又重开的情况，需要通过真实页面操作验证。
- 尺寸排序不能修改真实筛选值，只能修改选项展示顺序和显示文本，否则会影响后端查询。
- 历史标签框加宽会占用更多横向空间，因此日期行和筛选行需要允许自然换行，不能再挤压开始日期。
- 历史日期行调整后，可能影响分页工具组的位置，需要回归每页数量和翻页按钮。
