## 历史记录页顶部压缩

历史记录页顶部改成单行布局：

```text
历史记录    状态    每页数量    筛选    刷新
```

实现规则：

- `历史记录` 标题、状态下拉框、每页数量下拉框、`筛选` 按钮、`刷新` 按钮全部放在同一排。
- `筛选` 按钮保留。
- `刷新` 按钮放在同一排靠右或紧跟筛选按钮，按实际宽度选择不造成横向溢出的排列。
- 窄屏时允许这排内容换行，但优先保持紧凑，不再拆成标题行和筛选行两大块。
- 顶部加载状态和错误信息仍在顶部控件下方显示，不遮挡控件。

## 历史记录分页信息压缩

历史记录页分页信息改成同一行：

```text
总数 7 · 第 1 / 1 页    上一页    下一页
```

实现规则：

- `总数` 与 `第 1 / 1 页` 挨着显示。
- 两者字体大小、颜色、行高保持一致。
- `上一页`、`下一页` 放在同一排。
- 这一行放在历史记录列表上方。
- 不再使用当前 `总数` 和 `第 1/1 页` 分散在不同块里的样式。

## 单条历史记录结构

每条历史记录保留两层结构：

```text
第一行：编号 / 状态 / 开始时间 / 耗时
第二行：提示词 / 参数 JSON / 小字区
```

第一行规则：

- 保留当前编号、状态、开始时间、耗时。
- 样式继续使用小字和状态胶囊。
- 不增加新的输入框。

第二行规则：

- 第二行整体宽度等于当前 V0.18 中提示词输入框所在内容宽度。
- 第二行固定为三部分，宽度比例为：

```text
提示词 : 参数 JSON : 小字区 = 1 : 1 : 2
```

- 宽屏和窄屏都保持 `1:1:2`，不改成上下排列。
- 三部分的总宽度不得超过历史记录卡片内容区，不允许横向溢出。
- 三部分之间保留少量间距，间距计入总宽度。
- 小字区内部分为上下两行：上面是参数摘要，下面是输出路径。
- 小字区上下两行的总高度不超过提示词框和参数 JSON 框的高度。

## 提示词区域

提示词区域只显示提示词内容，不显示 `提示词` 小标题。

实现规则：

- 使用只读框或等效的文本框样式展示提示词。
- 宽度为第二行第一栏。
- 高度与参数 JSON 框保持一致。
- 默认不出现滚动条。
- 内容过长时，框内可以做截断或隐藏溢出，但不能撑高整条历史记录。
- 鼠标悬停在提示词框上时，显示浮层，完整展示提示词全文。
- 点击提示词框时，浮层保持展开，用户可以选中文字并复制。
- 点击浮层外区域或切换到其他记录时，关闭当前浮层。
- 浮层必须允许文本选择，不得因为鼠标移动到浮层上就立刻消失。
- 浮层不得造成页面横向滚动。

## 参数 JSON 区域

参数 JSON 区域位于第二行第二栏：

```text
参数 JSON 框
```

参数 JSON 规则：

- 不显示 `参数 JSON` 小标题。
- 宽度为第二行第二栏。
- 高度与提示词框保持一致。
- 默认不出现滚动条。
- 内容过长时，框内可以做截断或隐藏溢出，但不能撑高整条历史记录。
- 鼠标悬停在参数 JSON 框上时，显示浮层，完整展示参数 JSON。
- 点击参数 JSON 框时，浮层保持展开，用户可以选中文字并复制。
- 点击浮层外区域或切换到其他记录时，关闭当前浮层。
- 浮层使用等宽字体，保留 JSON 换行和缩进。

## 小字区

小字区位于第二行第三栏，宽度为提示词栏的 2 倍。

小字区结构：

```text
上行：参数摘要
下行：输出路径
```

参数摘要规则：

- 参数摘要用小字显示。
- 显示内容沿用当前历史记录里的生成信息，例如：

```text
模式：文生图  Provider：AIAPIS  Adapter：openai  调用方式：image  尺寸：1024x1024  数量：1
```

- 内容过长时自动换行或截断，但不横向溢出。

输出路径规则：

- 输出路径放在参数摘要下面，用同样的小字显示。
- 不显示输入路径。
- 不再使用输出路径输入框。
- 如果有多个输出路径，逐条显示或用换行显示。
- 输出路径允许自动换行，长路径使用 `overflow-wrap: anywhere` 或等效样式，不能撑出页面。
- 如果没有输出路径，隐藏输出路径行。
- 小字区上下两行的总高度不超过提示词框和参数 JSON 框的高度。

## 删除历史记录路径输入框

从单条历史记录中去掉以下输入框：

```text
输入图片路径
输出图片路径
```

实现规则：

- 输入路径完全不显示。
- 输出路径改为第二行第三栏小字区里的文本。
- 历史记录仍保留后端返回的输入路径和输出路径数据，不改数据库字段。
- 本次只是前端展示方式改变。

## 错误信息展示

如果历史记录存在错误信息：

- 错误信息继续显示。
- 错误信息可以放在第二行下面，作为额外错误区。
- 错误信息不参与三栏布局，避免挤压提示词、参数 JSON 和小字区。
- 错误信息过长时也使用浮层全显或自动换行，不产生横向溢出。

## 调用示例默认直接显示

设置页中的调用示例内容必须默认直接显示，不需要点击 `编辑` 才显示。

实现规则：

- 去掉调用示例显示对 `editing` 状态的依赖。
- `调用示例` 页签激活时，固定调用示例 textarea 必须立即渲染内容。
- `自定义代码` 页签激活时，自定义代码 textarea 必须立即渲染内容。
- 默认进入设置页时显示 `调用示例` 页签。
- 如果自定义代码为空，不允许因为旧的 tab 状态显示一个空白自定义代码区。
- 如果自定义代码非空，可以保持或切换到自定义代码页签，但必须显示 textarea 内容和醒目提示。
- `编辑` 按钮不再控制代码是否显示，只控制用户是否正在主动编辑固定示例。

## 调用示例编辑状态

为了彻底避免“点击编辑才显示内容”的反复问题，V0.19 将调用示例区域按默认可见、默认可编辑处理。

实现规则：

- 固定调用示例 textarea 默认显示内容。
- 固定调用示例 textarea 默认可编辑。
- `编辑` 按钮默认呈现高亮状态，表示当前区域可编辑。
- `保存` 保存当前示例内容。
- `取消` 恢复到上一次保存的示例内容。
- `复制` 复制当前显示页签中的代码全文。
- 代码框根据内容自动增高，不出现纵向滚动条。
- 长行自动换行，不产生横向滚动。
- 不使用 `display: none` 隐藏当前应该显示的代码面板。

保留这一行：

```text
调用示例    自定义代码                                      编辑    保存    取消    复制
```

不恢复单独的外层 `调用示例` 小标题。

- 代码区域背景、边框、字体继续保持当前风格。

## 副作用与处理

历史记录页采用三栏后，提示词和参数 JSON 的单列宽度会变窄。通过悬停浮层和点击固定浮层解决长内容查看、选中、复制问题。

历史记录页去掉输入路径展示后，页面更紧凑，但不能直接从历史记录页看到输入图片路径。本次按需求只保留输出路径展示；原始输入路径数据仍保留在后端记录中，不删除。

输出路径从输入框改为小字文本后，不再像输入框一样有内部滚动。长路径必须自动换行，避免横向溢出。

调用示例默认可编辑后，误改固定示例的概率比只读状态更高。通过 `取消` 恢复上一次保存内容，通过 `保存` 明确提交修改。

调用示例不再依赖隐藏面板和编辑状态显示内容，会减少空白显示问题，但需要同步调整复制、保存、取消逻辑，确保当前页签和当前 textarea 一致。
