## 修改目标

V0.27 重点处理大量实例后的保存区和历史记录稳定性，并增加保存区批量管理。

主要目标：

- 保存区继续使用分页。
- 保存区搜索、标签筛选、来源筛选、方式筛选、排序继续走后端查询。
- 历史记录页继续使用后端分页。
- 图片显示增加懒加载，避免页面外图片提前加载太多。
- 保存区增加当前页批量选择。
- 批量操作先支持批量添加标签、批量删除标签、批量删除实例。
- 不做批量修改来源。
- 不做批量修改 Provider。
- 不做缩略图缓存。
- 不改变数据安全页备份、导出、恢复的核心逻辑。
- 不破坏 V0.26 Provider 能力体系。

## 不做内容

V0.27 不做以下内容：

- 不引入缩略图缓存。
- 不新增 Pillow 或其他图片处理依赖。
- 不复制原图。
- 不改变原图仍以本地路径读取的规则。
- 不做跨页全选。
- 不做批量修改来源。
- 不做批量修改 Provider。
- 不修改历史记录里的 Provider、adapter、调用方式、参数快照。
- 不新增前端框架。
- 不引入打包器。
- 不把 JS 重新堆回 `frontend/app.js`。
- 不把 CSS 重新堆回 `frontend/styles.css`。
- 不改坏数据安全页、备份、导出、恢复。

## 性能原则

保存区实例数量变多后，前端只保存和渲染当前页数据。

保存区列表查询必须由后端完成：

```text
搜索提示词
标签筛选
无标签筛选
来源筛选
方式筛选
排序
分页
```

前端不能为了筛选而一次性加载全部实例。

历史记录页继续由后端分页查询，前端不能一次性加载全部历史记录。

单列 / 双列切换只重排当前页 DOM，不触发全量实例加载。

## 图片懒加载

保存区和操作区图片的 `<img>` 增加浏览器原生懒加载：

```html
<img loading="lazy" decoding="async">
```

要求：

- 当前可见区域图片优先加载。
- 页面外图片不提前加载太多。
- 图片点击查看大图逻辑不变。
- 图片悬停预览逻辑不变。
- 图片路径仍然来自数据库中的本地路径。
- 不生成缩略图。
- 不复制原图。

如果浏览器不支持 `loading="lazy"`，仍按原有图片显示逻辑工作。

## 缩略图缓存结论

V0.27 先不做缩略图缓存。

原因：

- 当前版本目标是先提升当前页渲染稳定性和批量管理。
- 缩略图缓存会引入图片处理依赖和缓存失效问题。
- 原图可能被用户移动、替换或删除，缩略图缓存需要额外一致性策略。

后续如果要做缩略图缓存，另开版本讨论。

可选后续方向：

```text
AI生图软件/cache/thumbnails/
```

原图仍然只保存本地路径，缩略图只是可删除、可重建的派生缓存。

## 保存区筛选调整

### 标签筛选立即生效

生图管理页保存区的标签筛选不再需要旁边的 `筛选` 按钮。

行为：

- 点击某个 TAG 后立即刷新保存区。
- 点击清空标签筛选后立即刷新保存区。
- 标签筛选下拉中的搜索框只过滤下拉选项，不立即刷新保存区。
- 普通搜索提示词仍保留搜索按钮或回车触发。

### 无标签筛选

标签筛选下拉中新增选项：

```text
无
```

内部值使用：

```text
__untagged__
```

行为：

- 勾选 `无` 后，其他已选 TAG 自动取消。
- 勾选任意普通 TAG 后，`无` 自动取消。
- `无` 表示筛选所有没有任何标签的实例。
- `无` 不作为真实 TAG 写入数据库。
- `无` 不出现在实例标签编辑器里。
- `无` 不出现在新增标签、批量添加标签的可选 TAG 中。

后端查询逻辑：

```sql
NOT EXISTS (
  SELECT 1
  FROM instance_tags
  WHERE instance_tags.instance_id = instances.id
)
```

### 来源筛选文案

来源筛选下拉菜单中：

```text
手动保存
```

改为：

```text
手动
```

内部值仍为：

```text
manual
```

生成实例的显示文案仍可保持当前实例卡片里的来源文案，不强制改。

### 方式筛选

新增 `方式筛选`，单选下拉。

选项：

```text
全部
文生图
图生图
有输出
无输出
```

内部值：

```text
all
text_to_image
image_to_image
has_output
no_output
```

筛选逻辑：

- `全部`：不增加方式条件。
- `文生图`：没有输入图的实例。
- `图生图`：有至少 1 张输入图的实例。
- `有输出`：`output_image_path` 不为空。
- `无输出`：`output_image_path` 为空。

这里的 `文生图 / 图生图` 按输入图数量判断，不按 `instances.mode` 字段判断。

后端查询逻辑：

```sql
-- 文生图
NOT EXISTS (
  SELECT 1
  FROM input_images
  WHERE input_images.instance_id = instances.id
)

-- 图生图
EXISTS (
  SELECT 1
  FROM input_images
  WHERE input_images.instance_id = instances.id
)

-- 有输出
output_image_path <> ''

-- 无输出
output_image_path = ''
```

### 下拉类筛选立即刷新

以下控件选择后立即刷新保存区：

```text
标签筛选
来源筛选
方式筛选
排序
每页数量
显示方式
```

保存区工具栏不再显示独立的 `筛选` 按钮。

提示词搜索仍按当前逻辑保留按钮和回车触发，避免用户每输入一个字都请求后端。

### 工具栏文案和宽度

保存区工具栏调整：

- `路径批量替换` 改为 `路径替换`。
- `新增实例` 改为 `新增`。
- `来源筛选` 框宽度减小到能完整显示 `来源筛选` 和当前选项。
- `排序` 框宽度减小到能完整显示当前选项。
- `每页数量` 框宽度减小到能完整显示当前选项。
- `显示方式` 框宽度减小到能完整显示当前选项。
- 省出的宽度加给标签筛选框。
- 页面不能出现横向滚动条。

## 批量选择

保存区新增批量选择功能。

选择范围：

- 只能选择当前页实例。
- 不默认跨页全选。
- 翻页后清空选择。
- 改变搜索、标签、来源、方式、排序、每页数量后清空选择。
- 单列 / 双列切换后保留当前页选择。

实例卡片增加选择框：

```text
□
```

位置：

- 放在实例编号附近。
- 不挤压提示词、输入图、输出图。
- 不影响编辑、删除、重新提交按钮。
- `生成中` 临时实例不参与批量选择。

工具栏新增：

```text

批量添加标签
批量删除标签
批量删除
清空选择
```

当未选择实例时，批量操作按钮置灰。

## 批量添加标签

入口：

```text
批量添加标签
```

行为：

- 对当前已选实例添加一个或多个 TAG。
- 可以从已有 TAG 中选择。
- 可以新加 TAG。
- 不重复添加同名 TAG。
- 成功后刷新当前页和 TAG 列表。
- 保留当前筛选条件。
- 批量操作完成后清空选择。

```text

```

请求体：

```json
{
  "ids": [1, 2, 3],
  "tags": ["产品", "精选"]
}
```

响应：

```json
{
  "updated": 3
}
```

## 批量删除标签

入口：

```text
批量删除标签
```

行为：

- 对当前已选实例删除一个或多个 TAG。
- 只删除这些实例上的 TAG 关联。
- 不删除 TAG 表里仍被其他实例使用的 TAG。
- 成功后刷新当前页和 TAG 列表。
- 保留当前筛选条件。
- 批量操作完成后清空选择。

后端建议新增 API：

```text
POST /api/instances/batch/tags/remove
```

请求体：

```json

  "ids": [1, 2, 3],
  "tags": ["产品", "精选"]

```

响应：

```json

  "updated": 3
```

## 批量删除实例

入口：

```text
批量删除
```

删除前必须二次确认。

确认文案必须明确：

```text
确认删除已选 N 个实例？
这只会删除软件数据库中的实例记录，不会删除电脑上的图片文件。
```

行为：

- 删除当前已选实例。
- 不删除电脑上的图片文件。
- 不删除原图。
- 不删除输出图文件。
- 删除后刷新当前页和 TAG 列表。
- 如果删除后当前页变空，沿用 V0.22 的避免空白页逻辑，自动回到有数据的页。
- 批量删除完成后清空选择。

后端建议新增 API：

```text
POST /api/instances/batch/delete
```

请求体：

```json
{
  "ids": [1, 2, 3]
}
```

响应：

```json
{
  "deleted": 3
}
```

## 不做批量修改来源和 Provider

V0.27 不做批量修改来源。

原因：

- `source` 会影响实例是手动收藏还是软件生成，含义不是普通标签。
- 批量修改容易把实例来源语义改乱。

V0.27 不做批量修改 Provider。

原因：

- V0.26 已经明确 Provider 作用域。
- 操作区 Provider 是生成用 Provider。
- 保存区实例 Provider 是记录信息。
- 历史记录里的 provider_key、adapter、openai_call_method、params_json 是当时生成快照。
- 批量修改实例 Provider 容易让实例显示信息和历史快照不一致。

如果以后要做批量修改 Provider，必须单独设计成：

```text
只修改保存区实例显示 Provider，不修改历史记录和生成参数快照。
```

## 生成中临时实例读秒

保存区新增的 `生成中` 临时实例，去掉 `生成中` 标题，改成读秒。

显示格式：

```text
0.0 s
1.3 s
12.8 s
```

规则：

- 计时从点击生成并成功创建前端临时实例开始。
- 精确到 0.1 s。
- 只作为前端显示。
- 不写入数据库。
- 生成成功后停止并移除临时实例。
- 生成失败后停止并移除临时实例。
- 取消或页面刷新后停止。
- 页面刷新后不恢复旧读秒。
- 多个并行生成任务各自独立计时。

实现建议：

- pending 实例记录 `started_at_ms = performance.now()`。
- 使用一个全局 interval，每 100 ms 更新当前页 pending 显示。
- 没有 pending 实例时清理 interval。
- 渲染函数中通过 `elapsed_ms` 或 helper 格式化读秒。
- 不要为每个 pending 实例创建独立 interval。

## 副作用与处理

批量选择会增加前端状态。处理方式是只保存当前页选择，翻页和筛选变化后清空，避免跨页误操作。

批量删除风险更高。必须二次确认，并在确认文案中明确不会删除电脑上的图片文件。

标签筛选点击后立即请求后端，用户连续快速点击时可能产生多个请求。实现时要以最新筛选状态为准，避免旧请求返回覆盖新结果。

移除保存区独立 `筛选` 按钮后，下拉类筛选变得更直接，但提示词搜索仍保留按钮和回车，避免输入过程中频繁请求。

`无` 是筛选选项，不是真实标签。实现时必须避免把 `__untagged__` 写入标签表或实例标签。

方式筛选中的文生图 / 图生图按输入图数量判断，不按 `mode` 字段判断。这样符合当前需求，但旧数据里 `mode` 字段和输入图数量不一致时，会以输入图数量为准。

图片懒加载依赖浏览器行为，不保证完全不加载页面外图片，但可以减少大部分提前加载。V0.27 不做缩略图缓存，因此超大原图在进入可视区域时仍可能有加载压力。

pending 读秒需要定时器。必须在没有 pending 实例时清理 interval，避免页面使用时间长后定时器累积。

批量添加 / 删除标签会改变当前筛选结果。如果用户当前正在按某个标签筛选，批量删除该标签后当前页可能减少或为空，需要沿用避免空白页逻辑。

批量操作完成后刷新 TAG 列表，可能导致标签筛选下拉选项变化，这是预期行为。

V0.27 不改数据安全导出格式。数据特别大时导出仍可能耗时，但前端不能把导出内容直接塞进页面显示。

V0.27 不批量修改 Provider，避免破坏 V0.26 的 Provider 作用域和历史参数快照一致性。
