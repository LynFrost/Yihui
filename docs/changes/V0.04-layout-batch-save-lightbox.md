## 保存区提示词为空

保存区实例允许提示词为空。

后端规则：

- `create_instance()` 和 `update_instance()` 不再因为 `prompt.strip()` 为空而抛出 `ValueError("提示词不能为空")`。
- 保存时仍然将非字符串提示词转成字符串。
- 空提示词保存为 `""`。

生成规则保持不变：

- `POST /api/generate` 仍然要求提示词非空。
- 操作区点击“生成”时，提示词为空仍然返回 `400`。
- 生成实例仍然不会保存空提示词。

测试调整：

- 原 `/api/instances` 空提示词返回 400 的测试改成允许创建空提示词实例。
- 新增 `PUT /api/instances/<id>` 能保存空提示词的测试。
- 保留 `POST /api/generate` 空提示词返回 400 的测试。

## 操作区固定布局

操作区横向列位置固定。

图生图模式布局：

```text
模式 / 提示词 / 尺寸 / 输入图 / 输出图 / 标签与路径 / 清空生成按钮
```

文生图模式布局：

```text
模式 / 提示词 / 尺寸 / 空输入图占位区 / 输出图 / 标签与路径 / 清空生成按钮
```

文生图模式不显示输入图区内容，但保留输入图区列宽，使输出图、标签、路径、清空/生成按钮与图生图模式位置一致。

文生图模式中间空白处理：

- 输入图区占位列不能显示边框、标题或加号。
- 提示词框横向加宽，填满文生图隐藏输入图区后可利用的空间。
- 页面不能出现横向溢出。

按钮对齐：

- 右侧“清空/生成”按钮列与左侧“文生图/图生图”按钮列在横向结构和纵向高度上对应。
- 两个按钮列使用相同按钮高度、相同间距。

路径对齐：

- 操作区生成路径输入框的下边缘与输入图框的下边缘对齐。
- 标签框位于路径框上方。
- Provider 文本位于标签框上方。

## 保存区实例布局

保存区不再显示生成路径。

实例布局重新定义为：

```text
元信息 / 提示词 / 输入图 / 输出图 / 标签区 / 操作按钮
```

标签区：

- 与操作区一样，上方预留 provider 文本位置。
- 自动生成实例显示 provider。
- 手动保存实例不显示 provider 文本，但保留同等高度的空位，确保标签框和操作区纵向对齐。
- 标签框下方不再显示生成路径。

单列与双列：

- 单列和双列都使用同一套字段顺序。
- 双列每个实例必须完整落在自己的列内，不能撑出页面横向滚动。
- 单列时提示词和输入图片区可相应变宽。
- 切换单列/双列后，当前设置继续保存到 `settings.save_layout`。

单列/双列切换样式：

- 当前选中项不使用主按钮同款蓝底。
- 推荐使用浅灰底、深色边框、文字加粗或下划线作为选中状态。
- “筛选”“生成”等主操作按钮保留蓝底。
- 视觉上能明显区分“布局状态开关”和“主要操作按钮”。

## 保存区输入图片区

四张图一行的规则保留。

高度规则：

- 只按真实图片数量计算非编辑状态高度。
- 编辑状态的 `+` 添加位不得单独撑出空白第二行。
- 点击保存或取消退出编辑状态后，如果真实图片数量能放进一行，实例高度回到一行。
- 超过一行时，只有输入图区增加行高；元信息、提示词、输出图、标签区、操作按钮的位置保持稳定。

清理按钮：

- 保存区实例进入编辑模式后，在“输入图”标题右侧显示“清理”按钮。
- 点击“清理”后清空该实例草稿里的全部输入图。
- 按钮放在输入图区标题行内，不能额外占用新列。
- 非编辑状态不显示清理按钮。

## 批量保存

这里的行为名称是“批量保存”，不是自动保存。

触发规则：

- 点击某个保存区实例内部时，批量保存其他正在编辑的实例。
- 点击保存区所有实例以外区域时，批量保存全部正在编辑的实例。
- 点击当前正在编辑实例内部时，不保存当前实例。
- 点击图片弹窗、路径替换弹窗、标签下拉菜单、尺寸弹窗时，不触发批量保存。

保存方式：

- 对需要保存的每个编辑草稿调用现有保存逻辑。
- 保存成功的实例退出编辑状态。
- 保存失败的实例保留编辑状态。
- 顶部 message 显示失败信息。
- 保存失败不阻止用户点击当前目标区域。

并发规则：

- 批量保存期间避免重复提交同一个实例。
- 可以用 `state.savingInstances` 记录正在保存的实例 id。
- 如果同一个实例已经在保存中，本轮跳过它。

取消按钮：

- 点击某实例“取消”只取消当前实例草稿。
- 点击取消本身不触发保存其他实例，避免用户想取消时发生额外保存。

## 提示词输入与完整显示

操作区和保存区提示词框必须能正常输入。

适用范围：

- 操作区提示词。
- 保存区编辑状态提示词。
- 保存区非编辑状态提示词悬停。

显示规则：

- 鼠标悬停提示词框时，用浮层完整显示全部内容。
- 输入或聚焦提示词框时，也用同样的浮层完整显示全部内容。
- 浮层不改变实例或操作区整体高度。
- 浮层可以临时覆盖旁边内容。
- 浮层不能拦截 textarea 的点击和输入。
- textarea 本身保持可编辑，不能因为浮层盖住而无法输入。
- 原 textarea 不出现滚动条；长文本通过浮层看全。

实现建议：

- 浮层使用 `pointer-events: none`。
- 编辑态下 textarea 保持在可点击层。
- 只读态悬停显示浮层。
- 避免使用会让浮层自身维持 hover 的选择器导致遮挡按钮。

## 图片弹窗组内切换

图片弹窗打开时记录当前图片集合。

集合来源：

- 从操作区图片打开：集合为操作区全部输入图加输出图。
- 从某个保存区实例图片打开：集合为该实例全部输入图加输出图。

顺序：

```text
输入图 1
输入图 2
...
输入图 N
输出图
```

规则：

- 只在当前集合内切换，不切到其他实例图片。
- 没有输出图时不加入集合。
- 没有输入图时只包含输出图。
- 集合只有 1 张图时隐藏或禁用左右切换按钮。

交互：

- 弹窗左右两边显示上一张/下一张按钮。
- 键盘 `ArrowLeft` 切换上一张。
- 键盘 `ArrowRight` 切换下一张。
- `Escape` 仍然关闭弹窗。
- 鼠标滚轮缩放、拖动图片、加减缩放按钮继续保留。
- 切换图片时重置缩放和拖动偏移，使新图默认完整显示。

状态结构建议：

```js
state.lightbox = {
  path: "",
  gallery: [],
  galleryIndex: 0,
  zoom: 1,
  panX: 0,
  panY: 0
}
```

## 前端事件边界

点击图片槽：

- 打开弹窗前先同步当前可见输入状态。
- 根据图片槽所在区域构造 gallery。
- 操作区图片槽使用操作区 gallery。
- 保存区实例图片槽使用该实例 gallery。

点击实例区域：

- 判断目标是否在 `[data-instance-card]` 内。
- 如果在实例内，批量保存除该实例外的其他编辑草稿。
- 如果不在任何实例内，批量保存全部编辑草稿。
- 点击标签下拉、尺寸弹窗、图片弹窗、路径替换弹窗时跳过批量保存。
