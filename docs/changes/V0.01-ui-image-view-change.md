
## 操作区样式

操作区保持两个实例宽度。

操作区和保存区单个实例使用同一套基础组件样式：

- 外框
- 圆角
- 边框
- 提示词输入框
- 输入图图片位
- 输出图图片位
- 标签输入和标签列表
- 路径输入
- 按钮
- 行内间距

操作区唯一允许的差异：

- 输入图片区横向空间更大，可以容纳更多图片后再换行。

实现方式：

- 保留操作区横跨两列的布局。
- 继续使用 `.image-record`、`.record-row`、`.image-slot` 等共享类。
- 不给操作区单独做一套大面板视觉。
- 只为操作区输入图片区添加必要的宽度分配规则。

## 图片位控制层

已有图片的图片位默认只显示图片。

鼠标移入已有图片位时显示：

- 图片路径
- 删除按钮
- 替换按钮

鼠标移出后隐藏这些元素。

空图片位始终显示添加入口 `+`。

实现方式：

- 给已有图片的图片位增加填充状态类，例如 `.image-slot-filled`。
- 图片铺满图片位。
- 路径文字和按钮使用绝对定位 overlay。
- overlay 不参与图片位高度计算。
- 默认隐藏 overlay：

```css
.image-slot-filled .slot-overlay,
.image-slot-filled .slot-remove,
.image-slot-filled .slot-add {
  opacity: 0;
  pointer-events: none;
}
```

- hover 和键盘聚焦时显示 overlay：

```css
.image-slot-filled:hover .slot-overlay,
.image-slot-filled:hover .slot-remove,
.image-slot-filled:hover .slot-add,
.image-slot-filled:focus-within .slot-overlay,
.image-slot-filled:focus-within .slot-remove,
.image-slot-filled:focus-within .slot-add {
  opacity: 1;
  pointer-events: auto;
}
```

- 删除、替换、添加按钮点击时阻止事件冒泡，避免触发图片查看弹窗。

## 标签和路径输入

不显示这些标题：

```text
标签
路径
标签 / 路径
```

用 placeholder 表明输入框用途：

```text
添加标签
生成路径
```

placeholder 只使用浏览器默认行为：输入框有内容后自然消失。不做强制光标跳到开头的特殊逻辑。

操作区：

- 标签输入框 placeholder 为 `添加标签`。
- 路径输入框 placeholder 为 `生成路径`。
- 路径输入框旁边保留选择按钮。

保存区实例：

- 只读状态直接显示标签列表。
- 编辑状态显示标签输入框，placeholder 为 `添加标签`。
- 路径使用输入框式只读展示或同等视觉样式。
- 没有路径时显示 `生成路径` 空态提示。
- 不增加保存区路径编辑功能。

## 图片查看弹窗

单击已有输入图或输出图，在当前页面打开图片查看弹窗。

不打开新标签。

弹窗只显示大图，不显示路径和复制路径按钮。

弹窗支持：

- 默认适应窗口。
- 鼠标滚轮缩放。
- `+` 放大。
- `-` 缩小。
- `适应窗口` 恢复默认缩放。
- `Esc` 关闭。
- 点击背景关闭。

实现方式：

- 复用现有图片接口：

```text
/api/image?path=...
```

- 图片位保存原始路径到 `data-image-path`。
- 点击已有图片位时读取 `data-image-path` 并打开 lightbox。
- 删除、替换、添加按钮点击时不打开 lightbox。
- 图片加载失败时，在弹窗内显示加载失败提示。
- 加载失败不修改实例数据。

建议前端状态：

```javascript
state.lightbox = {
  path: "",
  zoom: 1,
  error: ""
};
```

缩放限制：

```text
最小：0.25
最大：5
步进：0.25
```

## 事件处理规则

图片位点击：

- 有图片路径：打开图片查看弹窗。
- 无图片路径：不打开弹窗。

按钮点击：

- 删除图片：删除数据库中的图片路径引用，不删除电脑上的图片文件。
- 添加/替换图片：打开图片选择窗口。
- 按钮事件调用 `event.stopPropagation()`。

键盘：

- `Esc`：关闭图片查看弹窗。
