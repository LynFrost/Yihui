## 修改目标

V0.43 的目标是补齐保存区批量选择体验：

- 缩略图模式下可以批量选择实例。
- 缩略图模式下可以点击 `全选`。
- 缩略图模式下可以勾选单个缩略图。
- 缩略图模式下支持 `Shift` 连选。
- 缩略图模式下选中实例后，可以执行所有现有多选相关操作。
- 列表模式下保存区实例支持 `Shift` 连选。
- 列表模式下选择框旁边的 `选择` 文字去掉，只保留选择框。

本版不做：

- 不新增新的批量操作类型。
- 不新增跨页全选。
- 不新增批量 Provider 修改。
- 不改变节点、标签、历史记录、数据安全页的大功能。
- 不改变缩略图缓存策略。
- 不改变缩略图模式下图片悬停预览和点击大图能力。
- 不改变生成中实例唯一性和读秒逻辑。

## 当前状态

V0.36 中缩略图模式只是浏览模式：

- 缩略图模式下 `currentPageSelectableIds()` 返回空数组。
- 缩略图模式下 `全选`、`取消`、`添加标签`、`删除标签`、`移动`、`删除` 等批量按钮被置灰。
- 缩略图 tile 点击用于打开大图。
- 缩略图 tile 没有选择框。
- 列表模式中只有单个 checkbox 切换，没有 `Shift` 连选锚点。

V0.43 需要废弃“缩略图模式不能批量选择”的旧规则。

## 选择状态统一规则

### 选择集合

继续使用现有前端状态：

```javascript
state.selectedInstanceIds
```

要求：

- 列表模式和缩略图模式共用同一个选择集合。
- 选择集合只保存当前页可选实例的 id。
- 翻页、筛选、排序、每页数量变化后，继续沿用 V0.27 规则清空选择。
- 切换列表模式和缩略图模式时不强制清空选择。
- 如果切换模式后当前页仍包含已选实例，继续显示选中状态。
- 如果刷新实例列表后某些已选 id 已不在当前页，需要从选择集合中剔除。

### 可选实例

当前页可选实例定义为：

- 正式实例。
- 非生成中实例。
- 有输出图、无输出图、失败实例都可以选择。

不可选实例：

- `pending = true` 的临时生成中实例。
- `generation_status = running` 的生成中实例。
- 后端尚未返回真实 id 的过程实例。

原因：

- 生成中实例会被 pending 合并逻辑替换。
- 如果允许选择生成中实例，生成完成后容易出现选择状态丢失或错选。

### 当前页可选 id

`currentPageSelectableIds()` 不再因为缩略图模式返回空。

新规则：

```text
当前页实例列表中，排除 pending / running 后的正式实例 id。
```

列表模式和缩略图模式都使用同一套可选 id 顺序。

## Shift 连选规则

### 基础规则

新增一个前端选择锚点，例如：

```javascript
state.lastSelectedInstanceId
```

或同等命名。

规则：

- 普通点击某个选择框时，切换该实例选中状态，并把它设为新的连选锚点。
- `Shift` 点击某个选择框时，如果存在有效锚点，则选中锚点到当前实例之间的所有当前页可选实例。
- 如果没有有效锚点，`Shift` 点击等同普通点击。
- 如果锚点不在当前页可选列表中，`Shift` 点击等同普通点击，并重置锚点。
- 连选范围按当前页、当前筛选、当前排序后的显示顺序计算。
- 连选范围中的生成中实例必须跳过。

### 连选方向

无论从上到下还是从下到上，都按两个 id 在当前页可选列表中的位置取闭区间。

示例：

```text
当前页可选顺序：1, 2, 3, 4, 5
先点 2，再 Shift 点 5 -> 选中 2, 3, 4, 5
先点 5，再 Shift 点 2 -> 选中 2, 3, 4, 5
```

### 连选动作

`Shift` 连选建议统一为“添加选中”，不做反向批量取消。

也就是说：

- 不管当前目标实例之前是否已选，`Shift` 点击都把范围内实例加入选中集合。
- 如需取消，用户可以单点取消，或点 `取消` 清空选择。

这样最容易理解，也能避免范围内一部分已选、一部分未选时行为混乱。

### 清空锚点

以下操作需要清空连选锚点：

- 点击 `取消`。
- 翻页。
- 搜索提示词变化并刷新。
- 标签筛选变化并刷新。
- 来源筛选变化并刷新。
- 方式筛选变化并刷新。
- 排序变化并刷新。
- 每页数量变化并刷新。
- 节点筛选变化并刷新。
- 批量删除完成后。
- 批量移动完成后。
- 当前页刷新后锚点实例不存在。

以下操作可以保留或重设锚点：

- 单点选择实例后，锚点变为该实例。
- `全选` 后，锚点可以设置为当前页最后一个可选实例。
- 批量添加标签、批量删除标签完成后，如果实例仍在当前页，可以保留选择集合；如果现有逻辑会清空选择，则同步清空锚点。

## 缩略图模式选择交互

### 选择框位置

缩略图 tile 左上角增加一个小选择框。

要求：

- 选择框位于 tile 左上角。
- 未选中时，只有鼠标移到 tile 上才显示。
- 选中后，选择框一直显示。
- 键盘焦点落到选择框时，选择框也必须显示。
- 选择框尺寸要小，不能遮挡太多缩略图内容。
- 选择框使用真实 checkbox 或具备等效可访问语义的按钮。

建议结构：

```html
<button class="save-thumbnail-tile ...">
  <input
    type="checkbox"
    class="thumbnail-select-checkbox"
    data-action="toggle-select-instance"
    data-id="..."
  >
  <img ...>
</button>
```

如果实际实现中 checkbox 放在 button 内会造成 HTML 交互嵌套问题，也可以改成：

```html
<div class="save-thumbnail-tile ...">
  <label class="thumbnail-select">
    <input ...>
  </label>
  <button class="thumbnail-image-button" data-image-path="...">
    <img ...>
  </button>
</div>
```

推荐第二种结构，避免 checkbox 和 button 嵌套带来的事件问题。

### 选中状态

选中后的 tile 需要有明确视觉状态。

建议：

- tile 外框高亮。
- 左上角 checkbox 常显。
- 可以增加轻微半透明遮罩或角标，但不要影响图片识别。

要求：

- 选中态不能导致 tile 尺寸变化。
- 选中态不能让缩略图网格跳动。
- 选中态在宽屏和窄屏都清楚。

### 点击区域规则

缩略图模式中必须严格区分选择和看图：

- 点击左上角选择框：只选择或取消选择。
- `Shift` 点击左上角选择框：执行连选。
- 点击图片主体：打开大图弹窗。
- 鼠标悬停图片主体：继续显示临时大图预览。
- 鼠标悬停选择框本身时，不应触发错误的大图打开。
- 空白 tile、失败 tile、无输出 tile 没有大图可打开，但仍可以通过选择框选择。
- 生成中 tile 不显示选择框，不参与选择，不参与批量操作。

### 缩略图模式全选

缩略图模式下 `全选` 按钮恢复可用。

规则：

- 只全选当前页可选实例。
- 不跨页全选。
- 不选中生成中实例。
- 全选后 `已选 X` 正常更新。
- 全选后可以执行添加标签、删除标签、移动、删除等现有批量操作。

### 缩略图模式批量操作

缩略图模式下以下按钮不再因为缩略图模式置灰：

```text
全选
取消
添加标签
删除标签
移动
删除
```

置灰规则改为：

- 当前页没有可选实例时，`全选` 置灰。
- 已选数量为 0 时，`取消`、`添加标签`、`删除标签`、`移动`、`删除` 置灰。
- 已选数量大于 0 时，上述批量操作可用。

批量操作语义保持不变：

- 批量添加标签只改数据库标签关联。
- 批量删除标签只删实例上的标签关联。
- 批量移动只改节点归属。
- 批量删除只删除软件数据库实例记录。
- 批量删除仍然必须确认。
- 所有批量操作都不删除电脑上的图片文件。

## 列表模式选择交互

### 去掉“选择”文字

列表模式保存区实例选择框旁边的 `选择` 文字去掉。

要求：

- 只保留 checkbox。
- checkbox 位置尽量保持当前布局。
- 实例卡片整体宽度、高度不应明显变化。
- 需要保留 `title` 或 `aria-label`，例如 `选择实例`。

### 列表模式 Shift 连选

列表模式 checkbox 也支持 `Shift` 连选。

规则与缩略图模式一致：

- 普通点击设置连选锚点。
- `Shift` 点击按当前页可选顺序连选。
- 生成中实例跳过。
- 翻页、筛选、排序等刷新动作清空锚点。

### 点击冲突

列表模式中只在 checkbox 上触发选择。

要求：

- 点击实例图片仍按原规则打开大图或编辑。
- 点击提示词、TAG、按钮、输入框不触发选择。
- 编辑、删除、移动、带入、复制提交、重新提交等按钮不受影响。

## 与缩略图悬停预览和大图弹窗的关系

V0.43 不能破坏以下能力：

- 缩略图模式图片悬停临时预览。
- 缩略图模式点击图片打开大图。
- 普通列表模式图片悬停临时预览。
- 普通列表模式点击图片打开大图。
- 大图弹窗左右切换。
- 大图弹窗键盘左右切换。
- 大图弹窗关闭。

缩略图模式下大图切换范围继续沿用 V0.36 规则：

- 只在当前缩略图网格中有输出图的实例之间切换。
- 不混入输入图。
- 不混入操作区图片。
- 不混入隐藏页或其他页图片。

## 与生成中实例的关系

生成中实例继续遵守 V0.28 至 V0.30 的过程规则：

- 点击生成后只显示一个对应生成中过程实例。
- 生成中实例显示读秒。
- 生成中实例不显示选择框。
- 生成中实例不参与全选。
- 生成中实例不参与 Shift 连选。
- 生成中实例不参与批量操作。
- 生成完成后最终实例变成可选。
- 生成失败后失败实例可选。

如果生成完成后刷新当前页：

- 按当前排序、分页、节点、筛选规则决定最终实例位置。
- 如果最终实例在当前页且不再是 running，就可以被选择。
- 不自动选中新生成实例。

## 与筛选、排序、分页、节点的关系

以下动作仍然按既有规则刷新保存区，并清空当前页选择：

- 搜索提示词。
- 标签筛选。
- 来源筛选。
- 方式筛选。
- 排序。
- 每页数量。
- 节点筛选。
- 首页、上一页、下一页、尾页。

V0.43 需要额外保证：

## 与撤销 / 重做的关系

撤销 / 重做作用范围继续沿用 V0.30，不扩大范围。

要求：

- 选择状态本身不进入撤销 / 重做历史。
- 批量添加标签、批量删除标签、批量移动、批量删除等已有可撤销操作继续照常。
- 撤销或重做后刷新保存区时，应剔除当前页不存在的已选 id，并清空无效 Shift 锚点。
- 撤销 / 重做按钮样式和翻页按钮区分的规则不变。

## 可能副作用与处理

### 缩略图点击冲突

影响：

- 缩略图 tile 既能选择，又能打开大图。
- 如果事件处理不清楚，可能点选择框时打开大图，或点图片时误选。

处理：

- 选择框和图片按钮分成不同元素。
- 选择框点击阻止冒泡。
- 图片主体点击只负责打开大图。

### 批量删除误操作风险增加

影响：

- 缩略图模式下图片密度更高，批量选中后删除更快。

处理：

- 批量删除继续二次确认。
- 确认文案继续明确“不删除电脑上的图片文件”。
- 不做跨页全选。

### Shift 连选顺序误解

影响：

- 用户可能以为 Shift 连选跨页或跨筛选。

处理：

- 明确只按当前页当前显示顺序连选。
- 翻页、筛选、排序后清空选择和锚点。

### 生成中实例选择冲突

影响：

- 如果生成中实例被选中，生成完成后 id 或位置变化可能导致错选。

处理：

- 生成中实例不显示选择框。
- 全选和 Shift 连选都排除生成中实例。

### 选中态影响图片预览

影响：

- 选中边框或选择框可能遮挡图片。

处理：

- 选择框只占左上角小面积。
- 选中边框使用 `box-shadow` 或内描边，不改变尺寸。
- 悬停预览仍绑定图片主体。

### 普通列表布局变化

影响：

- 去掉 `选择` 文字后，实例头部可能更紧凑。

处理：

- 保持 checkbox 所在容器尺寸稳定。
- 不调整其他按钮位置。
- 不借此版本重新设计卡片布局。
