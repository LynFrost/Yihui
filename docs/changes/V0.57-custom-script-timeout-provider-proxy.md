# V0.57 自定义代码超时与 Provider 代理设置

## 版本目标

当前 V0.56 在实际生图时仍可能遇到几分钟后失败的问题。结合前面排查，至少有两类因素会影响成功率：

- 软件自定义代码执行存在 `180` 秒外层截断，长时间生成任务可能在供应商返回前被本地提前终止。
- 当前软件是否走系统代理不够明确，不同 Provider、不同供应商在直连或代理出口下的稳定性可能不同。

本版 V0.57 只做稳定性相关收口：

- 将自定义代码执行外层超时从 `180` 秒统一提高到 `900` 秒。
- 在设置页为每个 Provider 增加代理设置，可以选择系统代理、自定义代理或不走代理。
- 不新增大功能。
- 不改 Provider 能力体系。
- 不改保存区、历史记录、标签、节点、缩略图等业务流程。
- 不删除电脑上的图片文件。
- 文档确认后再执行实现；本文档落成不等于直接开始改代码。

## 修改项

### 1. 自定义代码执行外层超时从 180 秒改为 900 秒

当前问题：

- V0.56 中自定义代码执行由后端启动独立 Python 子进程。
- 当前外层超时为 `180` 秒。
- 如果供应商生成耗时超过 180 秒，即使供应商后续可能返回结果，本地也会先判定为 `自定义代码执行超时`。

调整方案：

- 全面排查和自定义代码执行相关的 `180` 秒超时。
- 将外层超时统一改为 `900` 秒。
- 建议集中成统一常量，例如 `CUSTOM_SCRIPT_TIMEOUT_SECONDS = 900`，避免多个文件各自写死。
- `run_custom_script` 默认超时改为 900 秒。
- 后端生成流程调用 `run_custom_script` 时显式使用 900 秒，避免未来默认值变化导致行为不清楚。
- 报错文案继续保留 `自定义代码执行超时`，可以补充显示 `900 秒`，方便用户判断是本地超时还是供应商错误。

不调整的内容：

- 不把 `自定义代码执行超时` 改成自动重试。
- 不改变已有脚本内部对 `502`、连接断开、下载失败等临时错误的重试逻辑。
- 不改变生成中实例、历史记录、保存区实例的核心流程。

验收标准：

- V0.57 中不存在仍用于自定义代码外层执行的 `180` 秒截断。
- 超过 180 秒但未超过 900 秒的自定义脚本不会被本地提前终止。
- 真正超过 900 秒时仍能终止子进程，并返回明确超时错误。
- 生成失败记录仍能正常写入历史记录。
- `自定义代码执行超时` 仍然不自动重试，避免重复扣费风险。

### 2. Provider 增加代理模式设置

当前问题：

- 当前内置 OpenAI 文生图、图生图脚本已经具备读取系统代理、自定义代理和关闭代理的基础能力。
- 但软件设置页没有把这些能力明确暴露给每个 Provider。
- 用户无法直观看到某个 Provider 当前是直连、走系统代理，还是走自定义代理。

调整方案：

- 在设置页每个 Provider 的连接信息区域增加代理设置。
- 每个 Provider 独立保存代理配置。
- 新增字段建议为：
  - `proxy_mode`：代理模式。
  - `proxy_url`：自定义代理地址。
  - `allow_untrusted_proxy_certificate`：是否允许不受信任代理证书。
- `proxy_mode` 支持三个值：
  - `system`：系统代理。
  - `custom`：自定义代理。
  - `none`：不走代理。
- 旧 Provider 和新建 Provider 默认使用 `system`，保持和当前脚本默认读取系统代理的行为一致。
- 只有选择 `custom` 时，自定义代理地址输入框才可编辑。
- 选择 `system` 时，使用系统代理设置。
- 选择 `none` 时，不使用系统代理，也不使用自定义代理。

界面建议：

- 放在设置页 Provider 的连接信息区域，不单独新增大块页面。
- 可使用一行或两行紧凑布局：
  - 代理模式下拉框。
  - 自定义代理地址输入框。
  - 允许不受信任代理证书开关或勾选项。
- 不改变设置页整体视觉风格。
- 不影响当前 base_url、api_key、api_key_env、model、user_agent 等字段。

验收标准：

- 每个 Provider 都可以单独选择 `系统代理 / 自定义代理 / 不走代理`。
- 切换 Provider 后，设置页显示对应 Provider 自己的代理配置。
- 新建 Provider 自动默认 `系统代理`。
- 旧 Provider 没有代理字段时，迁移或规范化后默认按 `系统代理` 处理。
- 自定义代理地址只在 `自定义代理` 模式下生效。
- 不走代理模式下，脚本不会读取系统代理。

### 3. 代理参数注入到自定义脚本上下文

当前要求：

- 软件最终生成功能需要按照设置页的 Provider 配置运行。
- Provider 的代理选择必须真正影响内置 OpenAI 文生图和图生图脚本。

调整方案：

- 后端生成时，将当前 Provider 的代理设置注入到自定义脚本上下文。
- 注入变量建议保持和现有共享脚本兼容：
  - `use_system_proxy`
  - `system_proxy`
  - `allow_untrusted_proxy_certificate`
- 映射规则：
  - `proxy_mode = system`
    - `use_system_proxy = True`
    - `system_proxy = ""`
  - `proxy_mode = custom`
    - `use_system_proxy = True`
    - `system_proxy = proxy_url`
  - `proxy_mode = none`
    - `use_system_proxy = False`
    - `system_proxy = ""`
- `allow_untrusted_proxy_certificate` 按 Provider 设置注入。

验收标准：

- 内置 `openai_text_to_image.py` 和 `openai_image_to_image.py` 能收到代理相关注入参数。
- `系统代理` 模式下，脚本使用系统代理。
- `自定义代理` 模式下，脚本使用指定代理地址。
- `不走代理` 模式下，脚本不使用系统代理。
- 完全自定义代码仍可自行读取这些注入变量，但不强制替用户代码改写网络请求。

### 4. 历史记录与排查信息

当前需求：

- 后续排查生成失败时，需要知道当次请求到底使用了哪种代理模式。

调整方案：

- 历史记录参数快照中记录当次 Provider 的代理模式。
- 建议记录：
  - `proxy_mode`
  - 是否允许不受信任代理证书
- 不记录 API Key。
- 自定义代理地址如记录，必须注意可能包含账号密码。为降低风险，建议历史记录只记录代理模式，不完整记录自定义代理 URL。

验收标准：

- 历史记录里可以判断当次请求是系统代理、自定义代理还是不走代理。
- 不泄露 API Key。
- 不在历史记录中明文保存带账号密码的代理 URL。

### 5. 数据安全、导出和恢复兼容

当前情况：

- Provider 设置属于软件核心配置，会被备份、导出、恢复覆盖到。
- 新增代理字段后，需要兼容旧数据库和旧导出文件。

调整方案：

- Provider 规范化逻辑为缺失字段补默认值：
  - `proxy_mode = system`
  - `proxy_url = ""`
  - `allow_untrusted_proxy_certificate` 使用与当前脚本兼容的默认值。
- 备份、导出、恢复继续包含 Provider 配置。
- 恢复旧数据时缺少代理字段不报错。
- 恢复新数据时保留代理设置。

风险提醒：

- 如果自定义代理 URL 中包含用户名、密码，这些内容会作为 Provider 配置进入备份和导出文件。
- 本版不做代理密码加密或单独密钥管理。
- 建议用户尽量不要在代理 URL 中写入敏感账号密码；如必须写入，需要自行保管备份文件。

验收标准：

- 旧数据库启动后 Provider 正常显示代理设置默认值。
- 旧导出文件恢复后不报错。
- 新导出文件恢复后代理配置仍存在。
- 备份、导出、恢复不删除电脑上的图片文件。

## 副作用与取舍

- 外层超时从 180 秒提高到 900 秒后，失败任务最长可能等待 15 分钟才返回。
- 如果同一 Provider 存在生成锁，同 Provider 后续任务可能排队更久。
- 如果供应商已经收到请求但长时间不返回，本地等待更久可能减少误杀，但无法避免供应商扣费后断流的问题。
- `自定义代码执行超时` 不自动重试，可以避免重复扣费，但也意味着超过 900 秒后仍需要用户手动重新提交。
- `系统代理` 模式会继续受 Windows 系统代理、本地代理软件和网络出口影响。
- `不走代理` 模式可能让部分 Provider 直接连接失败。
- `自定义代理` 地址写错会导致该 Provider 生图失败。
- 允许不受信任代理证书可以提高本地代理、证书中转场景的可用性，但会降低 TLS 校验严格性。
- 自定义代理 URL 如果包含账号密码，会进入 Provider 配置、备份和导出文件，本版只做提醒，不做加密。

## 测试重点

- 超时验证：
  - 检查代码中自定义代码外层执行不再使用 180 秒。
  - 使用模拟长时间脚本验证 180 秒后不会被杀掉。
  - 使用超过 900 秒的模拟超时或 mock 验证仍能超时终止。
- Provider 代理设置：
  - 新建 Provider 默认显示系统代理。
  - 旧 Provider 自动补齐代理字段。
  - 系统代理、自定义代理、不走代理三种模式切换后能保存和恢复。
  - 自定义代理地址输入框只在自定义代理模式下可编辑。
- 脚本注入：
  - 文生图脚本收到正确代理参数。
  - 图生图脚本收到正确代理参数。
  - 不走代理时脚本不读取系统代理。
  - 自定义代理时脚本使用指定代理。
- 实际生成：
  - 使用可用 Provider 分别测试系统代理和不走代理。
  - 对容易超过 180 秒的任务确认不会在 180 秒被本地截断。
  - 如果供应商返回 502、断流、PermissionDenied 等错误，仍按真实错误写入历史记录。
- 回归：
  - 设置页 Provider 切换、保存、调用示例不回退。
  - 文生图、图生图、自定义脚本不回退。
  - 保存区生成中、取消、历史记录写入不回退。
  - 数据安全页备份、导出、恢复不回退。
  - 标签、节点、缩略图视图、历史查询不受影响。
