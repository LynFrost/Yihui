## 修改目标

V0.30 在 V0.29 基础上做节点管理稳定性收口、过程实例显示收口、TAG 选择器交互收口，并补齐文档要求的有限范围撤销 / 还原。

主要目标：

- 节点管理支持稳定的新建、重命名、删除、进入子节点、返回上级路径。
- `全部 / 其他 / 新建 / 用户节点` 的层级逻辑与筛选语义保持一致。
- 节点筛选继续可与搜索、标签筛选、来源筛选、方式筛选、排序、分页叠加。
- 操作区生成、复制提交、重新提交产生的新实例继续进入当前所选节点。
- 单个移动、批量移动继续稳定，且不删除电脑上的图片文件。
- V0.29 的数据库 schema 升级、备份、导出、恢复继续稳定。
- 生成中读秒、翻页图片显示、TAG 弹出页关闭、TAG 清空不回退。
- 批量选择、批量标签、批量删除实例不被节点功能改坏。
- 生成中实例不再挤占正式实例编号，正式实例编号只在生成完成后重排。
- 节点区横向紧凑显示，去掉独立“新建”按钮。
- 在保存区增加有限范围的撤销 / 还原。

## 不做内容

V0.30 不做以下内容：

- 不引入缩略图缓存。
- 不新增新的数据库大功能。
- 不做跨页全选。
- 不做生成任务的撤销 / 还原。
- 不做路径替换、数据恢复、设置页修改的撤销 / 还原。
- 不删除电脑上的图片文件。
- 不改 Provider 能力体系。
- 不重拆前端 JS 模块。
- 不重拆 CSS 文件。

## 节点管理稳定性

### 节点区布局

节点区继续位于保存区筛选工具栏下方，改为横向紧凑布局。

布局要求：

- 节点区从左到右排列。
- 节点区字体比当前小一号。
- 每个节点选择框宽度按当前显示文字宽度决定，不额外留出明显空白。
- 单个节点框最大按 8 个汉字宽度显示。
- 超过 8 个汉字时，闭合状态下只显示前 8 个字。
- 鼠标悬停节点框时通过 `title` 显示完整节点名。
- 下拉菜单中的节点名称继续显示完整内容，不做 8 字截断。
- 节点区在窄屏时允许自然换行，不允许出现横向滚动条。

### 节点区“新建”入口

去掉节点区右侧独立的“新建”按钮。

新建规则统一为：

- 根层新建：通过第一个节点下拉中的 `新建`。
- 子层新建：通过当前层最后一个节点下拉中的 `新建`。

触发后：

1. 打开节点名称输入弹窗。
2. 输入节点名称。
3. 点击确认后调用 `POST /api/nodes`。
4. 创建成功后，当前路径自动进入该新节点。
5. `state.filters.page = 1`。
6. 清空当前页批量选择。
7. 保存 UI 状态。
8. 刷新保存区。

### 节点重命名

V0.30 补齐节点重命名前端入口，调用已有后端 `PATCH /api/nodes/<node_id>`。

交互规则：

- 只能对当前路径中最深的真实节点执行重命名。
- 当前没有选中真实节点时，重命名入口置灰。
- 点击重命名后打开节点名称输入弹窗。
- 输入为空、纯空格、保留名、同父节点重名时，保持弹窗并显示错误。
- 重命名成功后：
  - 当前路径保持在该节点。
  - 保存区立即刷新。
  - 持久化后的节点路径仍然有效。

### 节点删除

V0.30 补齐节点删除前端入口。

删除规则：

- 只能删除当前路径中最深的真实节点。
- 当前没有选中真实节点时，删除入口置灰。
- 删除必须二次确认。
- 删除节点不删除任何实例，不删除任何图片文件。
- 删除节点时，该节点以及其子节点下的实例整体上提到被删节点的父节点。
- 如果被删节点在根层，则这些实例的 `node_id = NULL`。
- 被删节点的子节点结构整体上提到父节点，不丢失层级顺序。
- 删除成功后：
  - 当前路径自动回退到被删节点的父节点。
  - 如果父节点不存在，则回到根层 `全部`。
  - `state.filters.page = 1`。
  - 清空当前页批量选择。
  - 保存 UI 状态。
  - 刷新保存区。

后端需要新增：

```http
DELETE /api/nodes/<node_id>
```

### 节点路径状态

前端节点路径状态继续持久化到 UI 状态中，但结构要完整表达每层当前选择。

目标结构：

```javascript
state.nodeFilter = {
  path: [
    { selection: "node", node_id: 1 },
    { selection: "all", node_id: 1 }
  ]
}
```

要求：

- 当前真实节点路径可从 `selection = "node"` 的项完整还原。
- 每一层当前选择必须能区分 `全部`、`其他`、`新建`、`某个真实节点`。
- 页面重新加载后，节点区显示状态与 `state.nodeFilter.path` 一致。
- 不能出现“内部状态已切换，但节点区仍显示根层全部”的情况。

### 节点筛选逻辑核对与修正

继续使用 V0.29 的后端筛选规则，但前端和页面显示必须完全对齐。

需要确认并修正：

- 根层 `全部` 显示全部实例。
- 根层 `其他` 只显示 `node_id IS NULL` 的实例。
- 真实节点后的 `全部` 显示当前节点及全部后代节点。
- 真实节点后的 `其他` 只显示直接属于当前节点、未进入子节点的实例。
- 节点筛选与提示词搜索、TAG 筛选、来源筛选、方式筛选、排序、分页叠加时，结果不互相覆盖。
- 节点路径切换后 `page=1`，清空当前页选择。

## 单个移动与批量移动

### 路径式移动弹窗

V0.30 中，单个移动、批量移动弹窗必须使用与节点区相同的路径式层级选择逻辑，不再使用平铺下拉。

交互规则：

- 第一层显示：`全部 / 其他 / 新建 / 根层节点...`
- 选中真实节点后，右侧出现下一层。
- 选择 `其他` 表示移动到当前层直属“未进入子节点”位置。
- 在根层选择 `其他` 表示 `node_id = NULL`。
- 在移动弹窗里选择 `新建` 时，也使用节点名称输入弹窗。
- 创建成功后，移动弹窗继续停留在当前打开状态，并自动进入新建节点。
- 点击确认后：
  - 单个移动调用 `POST /api/instances/<id>/move`
  - 批量移动调用 `POST /api/instances/batch/move`

### 稳定性要求

- 运行中实例仍然不能移动。
- 单个移动、批量移动后不删除图片文件。
- 若移动后实例不再属于当前筛选结果，则从当前页消失，并触发已有“避免空白页”逻辑。
- 批量移动后清空当前页选择。

## 撤销 / 还原

### 位置

在保存区顶部批量工具栏中，将撤销 / 还原按钮放在“总数”左边。

目标布局：

```text
全选当前页  已选 0  批量添加标签  批量删除标签  批量移动  批量删除  清空选择    撤销  还原  总数 123  首页  上一页  第 1 / 5 页  下一页  尾页
```

### 作用范围

V0.30 的撤销 / 还原只做“当前页面会话内”的有限范围操作，不持久化，不跨浏览器刷新。

纳入撤销栈的操作：

- 节点新建
- 节点重命名
- 节点删除
- 单个移动
- 批量移动
- 单个 TAG 添加
- 单个 TAG 删除
- 单个 TAG 清空
- 批量添加 TAG
- 批量删除 TAG
- 删除实例
- 新增手动实例

不纳入撤销栈的操作：

- 操作区生成
- 复制提交
- 重新提交
- 路径替换
- 数据恢复
- 数据导出
- 设置页保存

### 行为规则

- 页面首次打开时，撤销 / 还原按钮置灰。
- 执行一次可撤销操作后，撤销按钮亮起。
- 执行撤销后，如果可再还原，则还原按钮亮起。
- 浏览器刷新、关闭网页、切换版本目录后，撤销栈和还原栈清空。
- 每个撤销动作执行成功后刷新保存区。
- 若撤销失败，保留当前界面状态并显示错误。

## 生成中实例与正式编号

### 过程区与正式区分离

V0.30 中，生成中的临时实例不再插入正式保存区列表内部，不参与正式编号计算。

实现方式：

- 在保存区正式实例列表上方增加一个独立的“过程区”。
- 过程区只显示当前前端生成中的实例。
- 过程区中的实例继续显示读秒。
- 正式保存区继续只渲染数据库正式列表。

### 编号规则

- 正式保存区的 `#001 #002 #003` 只根据当前正式筛选 / 排序结果生成。
- 生成中的过程实例不占用正式编号。
- 生成未完成时，原本的 `#001` 继续保持 `#001`。
- 生成成功或失败后：
  - 成功：过程实例消失，正式实例进入正式保存区，再按当前筛选 / 排序重排编号。
  - 失败：过程实例消失，失败实例按现有失败保留规则进入正式保存区，再按当前筛选 / 排序重排编号。

### 过程区要求

- 过程区实例不参与批量选择。
- 过程区实例不参与当前页数量统计。
- 过程区实例不影响分页。
- 过程区支持与当前 V0.29 相同的读秒显示和生成中输出图状态显示。

## TAG 弹出页交互收口

### 保存区实例 TAG 弹出页

V0.30 中，保存区实例 TAG 选择器在点击某个 TAG 后必须继续保持打开，方便连续选择。

规则：

- 选择某个已有 TAG 后，不自动关闭弹出页。
- 新建一个 TAG 后，也不自动关闭弹出页。
- 只有点击弹出页外部区域，弹出页才关闭。
- 点击弹出页内部空白区域，不关闭。
- 点击实例以外区域、保存区空白区域、页面其他非弹窗控件区域时，弹出页关闭。

### 外部关闭规则

需要继续保证：

- 点击 `.tag-selector` 外部时，实例 TAG 弹出页关闭。
- 点击 `.tag-selector-menu` 内部时，不误关闭。
- 点击 `.modal-backdrop`、`.lightbox-backdrop`、批量 TAG 弹窗、路径替换弹窗内部时，不误触发实例 TAG 弹出页关闭逻辑。

## 数据安全、迁移、备份、导出、恢复

### schema 升级前备份

V0.30 中，迁移前备份触发条件改为：

- 数据库存在且 `schema_version < 3` 时，必须先创建 `pre_migration` 备份。
- `schema_version` 缺失、格式错误或元数据查询失败时，也必须先创建 `pre_migration` 备份。

### JSON 恢复

V0.30 中，数据安全页恢复入口支持两类文件：

- `.zip`：按整库恢复处理。
- `.json`：按导出的 JSON 恢复处理。

JSON 恢复规则：

1. 恢复前先创建 `pre_restore` 备份。
2. 先恢复 `nodes`。
3. 再恢复 `instances`。
4. 恢复 `input_images`、`tags`、`instance_tags`、`generation_history`、`app_metadata`。
5. 若实例引用的 `node_id` 不存在，则改为 `NULL`。
6. 恢复后重新写入规范化配置文件。
7. 不删除电脑上的图片文件。

### 数据安全页文案

数据安全页恢复卡片文案改为明确支持 JSON 恢复。

按钮文案：

- `选择恢复文件`
- `恢复当前文件`

说明文案：

- 支持 zip 整库恢复。
- 支持导出的 JSON 恢复。
- 恢复前会自动备份当前数据库。

## 风险与处理

### 节点删除风险

节点删除会改变实例归属和节点树结构。

处理：

- 删除前二次确认。
- 删除时不删图片文件。
- 实例与子树统一上提到父节点。
- 删除后自动回退到父节点路径。

### 撤销 / 还原风险

撤销范围扩大后，如果包含过多操作，会增加状态同步复杂度。

处理：

- 仅支持当前页面会话内的有限范围操作。
- 不纳入生成、恢复、路径替换、设置页修改。
- 不持久化。

### 过程区与正式区分离风险

过程实例与正式实例分离后，需要避免两边重复渲染和重复编号。

处理：

- 过程区只显示前端 pending 实例。
- 正式保存区只显示数据库正式列表。
- 生成成功 / 失败后立即清理过程区实例。

### JSON 恢复风险

JSON 恢复比 ZIP 恢复更容易出现字段不完整或节点引用失效。

处理：

- 恢复前自动备份。
