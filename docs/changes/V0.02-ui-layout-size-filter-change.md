## 数据库字段

自动生成的实例需要保存本次生成使用的尺寸参数。

在 `instances` 表增加字段：

```sql
generation_size TEXT NOT NULL DEFAULT ''
```

数据库初始化时兼容已有数据库：

- 如果 `instances.generation_size` 不存在，执行 `ALTER TABLE` 增加字段。
- 已有实例的 `generation_size` 保持空字符串。
- 手动新增实例的 `generation_size` 保持空字符串。
- 自动生成实例写入本次使用的尺寸，例如 `1024x1024`。

后端实例读写逻辑同步更新：

- `create_instance()` 接收并写入 `generation_size`。
- `update_instance()` 保留现有 `generation_size`，手动编辑实例时不编辑该字段。
- `hydrate_instance()` 返回 `generation_size`。
- 自动生成接口 `/api/generate` 创建实例时写入 `generation_size`。

## 生成尺寸参数

生成尺寸是全局默认参数，不按代理商单独保存。

配置文件继续使用全局字段：

```json
{
  "default_size": "1024x1024"
}
```

读取默认尺寸的优先级：

```text
settings.default_size
当前 provider.default_size
1024x1024
```

保存新的默认尺寸时只写入：

```text
settings.default_size
```

不要再写入或依赖：

```text
settings.providers[provider].default_size
```

保留读取 `provider.default_size` 的兼容逻辑，只用于旧配置兜底。

生成请求的 `options` 中写入：

```json
{
  "size": "1024x1024"
}
```

尺寸格式校验：

```text
^[1-9][0-9]*x[1-9][0-9]*$
```

只接受半角小写 `x`。不接受空格、中文乘号、逗号、负数、小数、空值。

常用预设：

```text
512x512
768x768
1024x1024
1024x768
768x1024
```

## 设置页面

设置页面移除 `default_size` 表单项。

设置页面保存时：

- 不渲染 `default_size` 输入框。
- 不从设置表单读取 `default_size`。
- 不覆盖 `settings.default_size`。
- 不写入 `providers[provider].default_size`。

已有配置文件中的 `default_size` 保留，用于操作区初始化和后续生成。

## 操作区尺寸按钮

在操作区中，将尺寸设置放在提示词和输入图之间。

操作区布局顺序：

```text
模式 / 提示词 / 尺寸 / 输入图 / 输出图 / 标签路径 / 操作按钮
```

尺寸列显示一个按钮：

```text
1024x1024
```

点击按钮后打开小浮层。浮层内容：

- 常用预设按钮。
- 一个自定义尺寸输入框。
- 确认按钮。
- 关闭按钮或点击外部关闭。

选择常用预设时：

- 立即把尺寸写入操作区状态。
- 同步保存为全局默认尺寸。
- 关闭浮层。

输入自定义尺寸并确认时：

- 校验格式。
- 校验失败时显示错误，不关闭浮层，不发起生成。
- 校验成功后写入操作区状态。
- 同步保存为全局默认尺寸。
- 关闭浮层。

生成时：

- 如果用户没有改尺寸，沿用当前全局默认尺寸。
- 如果用户改过尺寸，使用新尺寸。
- 请求 `/api/generate` 时将尺寸写入 `options.size`。
- 自动保存实例时将同一尺寸写入 `generation_size`。

清空操作区时：

- 清空提示词、输入图、输出图。
- 不清空标签。
- 不清空生成路径。
- 不清空当前尺寸。

## 图片位显示规则

图片位不拉伸图片。

已有图片显示规则：

- 图片高度撑满图片位。
- 图片保持原始比例。
- 如果图片宽度小于图片位宽度，水平居中显示。
- 如果图片宽度大于图片位宽度，宽度超出的部分在图片位内裁切。
- 图片不改变提示词、路径、按钮区域宽度。

CSS 使用方向：

```css
.image-slot img {
  width: 100%;
  height: 100%;
  object-fit: cover;
  object-position: center center;
}
```

输入图片区：

- 多张输入图在输入图片区内部横向排列。
- 显示不下时换到下一行。
- 每次换行增加标准图片位高度。
- 不挤压提示词、输出图、路径、按钮区域。

输出图片区：

- 只有一个输出图图片位。
- 高度与提示词主体一致。

图片位 hover 控制层继续保持 V0.01 行为：

- 默认只显示图片。
- 鼠标移入显示路径、删除、替换按钮。
- 鼠标移出隐藏。
- 空图片位始终显示 `+`。

## 图片查看弹窗

点击已有输入图或输出图，在当前页面打开查看弹窗。

弹窗默认显示完整图片，不需要拖动页面滚动条才能看完整。

弹窗布局：

- 使用 `position: fixed` 覆盖当前浏览器可视区域。
- 背景不滚动。
- 图片舞台使用可视区域剩余高度。
- 默认 `fit` 模式下图片完整显示在舞台内。

交互：

- 鼠标滚轮缩放。
- `+` 按钮放大。
- `-` 按钮缩小。
- `适应窗口` 恢复完整显示。
- 按住图片拖动可移动缩放后的图片。
- 点击图片外的背景关闭。
- `Esc` 关闭。

缩放规则：

```text
最小：0.25
最大：5
步进：0.25
```

拖动规则：

- 只有鼠标按住图片并移动时拖动。
- 松开鼠标结束拖动。
- 关闭弹窗后重置缩放和拖动偏移。
- 切换图片后重置缩放和拖动偏移。

## 后端标签接口

新增接口：

```text
GET /api/tags
```

返回数据库中当前仍被实例使用的全部 TAG：

```json
{
  "items": ["角色", "参考图", "海报"]
}
```

查询规则：

- 从 `tags`、`instance_tags` 联表查询。
- 只返回至少关联一个实例的 TAG。
- 去重。
- 按名称排序。

前端启动和保存区刷新后同步更新标签选项。

实例新增、删除、编辑标签后重新加载标签选项。

## API 和生成提供方

`/api/generate` 接收 `options.size`。

后端校验尺寸格式：

- 格式合法则传给 provider。
- 格式不合法返回 400。
- 缺失时使用全局默认尺寸。

`generate_image()` 将 `options` 原样传给 provider。

当前 AIAPIS provider 使用：

```python
options.get("size")
```

作为 `images.generate()` 或 `images.edit()` 的 `size` 参数。

provider 配置中的 `default_size` 只作为旧配置兜底。
