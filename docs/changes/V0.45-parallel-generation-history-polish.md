# V0.45 并行生成与历史记录体验收口

## 目标

V0.45 不新增大功能，只对 V0.44 并行生成和历史记录显示做稳定性收口。

## 变更内容

### 1. 生成中实例排序

- 当已有图片正在生成时，再次点击生成，新生成中的实例显示在旧生成中实例上方。
- 普通列表模式和缩略图模式都使用同一套生成中排序。
- 生成完成后仍按保存区正式实例列表规则显示。

### 2. 历史记录失败原因显示收口

- 历史记录卡片中失败原因最多显示最后 3 行。
- 悬停或点击浮窗仍显示完整失败原因。
- 完整错误内容不会被截断保存。

### 3. 历史记录浮窗切换时自动关闭

- 历史记录中点击固定的完整浮窗，在切换历史页、筛选、刷新或切换到其他页面时自动消失。
- 不再出现切页后旧浮窗残留的问题。

### 4. 生成成功后不回填操作区输出图

- 生成结果只更新保存区实例和历史记录。
- 不再把生成结果回填到操作区输出图。
- 避免多轮并行生成时，操作区当前提示词和旧任务结果不对应。

### 5. 历史记录复制按钮

- 每条历史记录的“带入”按钮右边增加“指令”“参数”“错误”三个按钮。
- “指令”复制完整提示词。
- “参数”复制完整参数 JSON。
- “错误”复制完整失败原因。
- 没有错误原因时，“错误”按钮置灰不可点。

## 不做内容

- 不改后端重试策略。
- 不改 OpenAI 脚本。
- 不改数据库 schema。
- 不调整 Provider 配置结构。

## 副作用与风险

- 操作区不再显示刚完成任务的输出图，需要在保存区查看结果。
- 历史记录单条记录更紧凑，但长错误需要通过浮窗或复制查看完整内容。
- 生成中显示顺序是“新任务在上”，完成后会回到正式列表排序，过程排序和最终排序可能短暂不同。

## 验收重点

- 连续点击生成时，新生成中的实例显示在旧生成中实例上方。
- 历史记录失败原因正文只显示最后 3 行，浮窗和复制仍是完整内容。
- 历史记录固定浮窗在翻页、筛选、刷新、切换页面后自动消失。
- 生成成功后操作区输出图不被旧任务结果覆盖。
- 历史记录“指令”“参数”“错误”复制按钮可用，没有错误时“错误”按钮置灰。
