## 修改目标

V0.35 在 V0.34 基础上做小范围 UI 和键盘交互收口：

- 将生图管理页操作区提示词框内部的 `X` 清空按钮，改为标题行右侧的 `清除` 按钮。
- 将保存区实例编辑状态提示词框内部的 `X` 清空按钮，改为标题行右侧的 `清除` 按钮。
- 保存区实例标题行同时存在 `清除` 和 `复制` 时，顺序为：`清除` 在左，`复制` 在右。
- 节点名称弹窗在新建节点和重命名节点时都支持 `Enter` 确认、`Esc` 取消。
- 缩短保存区批量工具栏按钮文案，节省横向空间。

本版只改前端显示和键盘行为，不改后端接口，不改数据库，不改图片加载和缩略图缓存逻辑。

## 提示词清除按钮

### 当前问题

V0.34 中，操作区和保存区实例编辑状态的提示词清空按钮位于 `textarea` 所在的提示词框内部。

当前结构类似：

```html
<div class="field-title-row">
  <span>提示词</span>
</div>
<div class="prompt-shell">
  <textarea>...</textarea>
  <button class="prompt-clear">×</button>
</div>
```

问题：

- `X` 按钮虽然视觉上很小，但在输入框内部会占用右侧一整列空间。
- 提示词框内可显示文字宽度被压缩。
- 长提示词编辑时不够舒服。

### 新结构

V0.35 将提示词清空按钮移动到标题行，文字改为：

```text
清除
```

操作区提示词标题行：

```text
提示词        清除
```

保存区实例编辑状态标题行：

```text
提示词        清除  复制
```

要求：

- `清除` 按钮放在 `提示词` 小标题右侧。
- 保存区实例如果同时显示 `复制`，按钮顺序必须是 `清除` 在左，`复制` 在右。
- `清除` 点击行为继续复用现有 `clear-operation-prompt` 和 `clear-instance-prompt`。
- `清除` 按钮继续带 `data-skip-batch-save="true"`，避免误触发批量保存。
- 操作区 `清除` 清空 `state.operation.prompt` 和 DOM 中的操作区提示词。
- 保存区实例 `清除` 只清空当前编辑草稿，不直接保存数据库。
- 保存区实例非编辑状态不显示 `清除`。
- 保存区实例非编辑状态继续保留 `复制`。
- 搜索提示词框内部的清空 `X` 不在本版修改范围内，继续保留。

### 推荐实现

当前提示词渲染集中在：

```text
frontend/js/render-operation.js
```

建议调整：

- `renderEditablePromptField` 中不再把 `clearButton` 插入 `prompt-shell`。
- 新增标题行按钮变量，例如 `clearTitleButton`。
- `clearTitleButton` 和 `copyButton` 都放进 `field-title-row`。
- 顺序固定为 `清除`、`复制`。

示例结构：

```html
<div class="field-title-row">
  <span>提示词</span>
  <span class="field-title-actions">
    <button type="button" class="field-title-action prompt-title-clear" data-action="clear-instance-prompt">清除</button>
    <button type="button" class="field-title-action" data-action="copy-instance-prompt">复制</button>
  </span>
</div>
<div class="prompt-shell">
  <textarea>...</textarea>
</div>
```

如果当前 CSS 已经支持 `field-title-action`，优先复用；只新增少量 `prompt-title-clear` 或 `field-title-actions` 样式。

## 提示词清除按钮样式

要求：

- `清除` 是小号文字按钮，和现有 `复制` 按钮风格保持一致。
- 不使用输入框内部绝对定位。
- 不遮挡提示词文字。
- 不改变提示词框高度。
- 不改变操作区和保存区实例整体布局。
- 窄窗口下不横向溢出。
- 标题行按钮过多时允许紧凑排列，但不能覆盖 `提示词` 小标题。

需要清理或调整：

- 操作区和保存区实例提示词不再需要内部 `.prompt-clear` 绝对定位样式。
- 搜索提示词框仍然使用 `.search-prompt-clear`，不要误删搜索框清空按钮样式。

注意：

`prompt-clear` 类如果仍被搜索框使用，不能全局删除；应只移除或停止使用操作区 / 实例提示词的内部按钮样式。

## 节点名称弹窗键盘行为

### 范围

V0.35 对节点名称弹窗统一补齐键盘行为。

范围包括：

- 新建节点弹窗。
- 重命名节点弹窗。

当前节点名称弹窗由同一个函数创建，建议在共享弹窗层统一处理。

相关文件：

```text
frontend/js/nodes.js
```

### 行为要求

当新建节点或重命名节点弹窗打开时：

- 按 `Enter`：确认。
- 按 `Esc`：取消。
- 点击取消按钮：取消。
- 点击弹窗背景：取消。
- 点击确认按钮：确认。

细节：

- `Enter` 确认时，如果名称为空、重名、使用保留名称等，继续显示现有错误，不关闭弹窗。
- `Esc` 取消时，不提交、不修改节点、不触发撤销记录。
- `Esc` 取消后关闭弹窗并回到生图管理页正常状态。
- `Esc` 取消不能触发保存区键盘翻页。
- `Esc` 取消不能影响图片弹窗的 `Esc` 关闭逻辑，因为节点名称弹窗打开时本来就会作为 modal 阻断保存区快捷键。

推荐实现：

```javascript
input?.addEventListener("keydown", (event) => {
  if (event.key === "Enter") {
    event.preventDefault();
    submit();
  }
  if (event.key === "Escape") {
    event.preventDefault();
    close(undefined);
  }
});
```

如果弹窗中未来增加多个输入控件，也可以把 `keydown` 绑定在 `dialog` 上，但 V0.35 保持最小改动，优先在当前输入框上补 `Escape`。

## 保存区批量工具栏文案

### 当前文案

V0.34 保存区批量工具栏当前文案：

```text
全选当前页
已选 X
批量添加标签
批量删除标签
批量移动
批量删除
清空选择
新增
```

这些文字偏长，占用工具栏横向空间。

### 新文案和顺序

V0.35 调整为：

```text
全选
取消
已选 X
添加标签
删除标签
移动
删除
新增
```

对应关系：

| V0.34 | V0.35 |
| --- | --- |
| 全选当前页 | 全选 |
| 清空选择 | 取消 |
| 批量添加标签 | 添加标签 |
| 批量删除标签 | 删除标签 |
| 批量移动 | 移动 |
| 批量删除 | 删除 |

顺序要求：

- `取消` 必须放在 `全选` 和 `已选 X` 中间。
- `已选 X` 继续显示当前选中数量。
- `新增` 继续保留在批量工具栏内。
- 撤销 / 重做 / 总数 / 首页 / 上一页 / 下一页 / 尾页区域不调整。

### 动作不变

只改按钮显示文字，不改 `data-action`。

必须继续使用现有动作：

```text
select-current-page
clear-selection
batch-add-tags
batch-remove-tags
batch-move-instances
batch-delete-instances
new-manual-instance
```

原因：

- 避免改动事件分发。
- 避免影响现有测试和批量操作逻辑。
- 降低回归风险。

### 弹窗和提示文字

V0.35 只要求缩短工具栏按钮文案。

以下内容可以继续保留 `批量` 二字：

- 批量添加标签弹窗标题。
- 批量删除标签弹窗标题。
- 批量移动弹窗标题。
- 删除确认弹窗中对多个实例的说明。
- 撤销 / 重做记录名称。
- 成功提示，例如 `已批量添加标签`。

原因：

- 这些文字不占工具栏宽度。
- 保留 `批量` 更能说明操作性质。
- 可以降低误解和误操作风险。

## 可能副作用与处理

### 标题行按钮变多

影响：

保存区实例编辑状态可能同时显示 `清除` 和 `复制`。

处理：

- 使用紧凑小按钮。
- 按钮顺序固定为 `清除`、`复制`。
- 标题行保持 `flex` 布局。
- 窄窗口下不得横向溢出。

### 清除按钮从框内移出后，旧 CSS 可能残留

影响：

如果旧 `.prompt-clear` 样式还在，可能造成无用样式残留。

处理：

- 操作区和实例提示词不再输出内部 `prompt-clear`。
- 搜索框内部清空按钮仍然使用 `search-prompt-clear`，不能误删。
- CSS 可保留兼容类，但不能影响新的标题行按钮。

### Esc 取消节点弹窗可能和全局 Escape 逻辑重叠

影响：

全局 `Escape` 已用于关闭图片弹窗、节点菜单等。

处理：

- 节点名称弹窗输入框内捕获 `Escape` 并 `preventDefault()`。
- 只关闭当前节点名称弹窗。
- 不触发其他全局快捷行为。

### 批量按钮文案变短后语义弱一点

影响：

`删除` 比 `批量删除` 更短，但也更需要明确当前作用对象。

处理：

- 保留 `已选 X` 紧挨在工具栏前部。
- 删除按钮继续使用危险样式。
- 删除动作继续弹确认框。
- 弹窗和成功提示可以保留 `批量` 二字。
