# V0.49 设置候选、长路径下拉与手动实例提交

## 版本目标

V0.49 在 V0.48 的基础上继续做高频操作收口：设置页连接字段增加成功值候选，操作区路径下拉完整显示长路径，保存区减少单卡按钮占用，并让手动实例可以直接提交生成。本版不新增大功能，不改 Provider 调用体系，不改数据安全、标签管理、历史记录和缩略图缓存核心逻辑。

## 修改内容

1. 设置页连接信息字段增加成功候选。
   - `api_key_env`、`model`、`user_agent` 保留手动输入。
   - 三个字段增加下拉候选，交互方式和操作区生成路径一致。
   - 候选值只在生图成功后记录，失败或未提交成功的临时值不写入候选。
   - 每类候选保留最近有限数量，避免 UI 状态无限膨胀。

2. 操作区生成路径下拉完整显示路径。
   - 生成路径继续支持手动输入。
   - 成功使用过的路径继续进入候选。
   - 下拉菜单改为自定义下拉，不再依赖原生 `datalist`。
   - 长路径完整显示；必要时下拉菜单可以向左或向右扩宽，但不能把操作区布局撑乱。

3. 保存区实例去掉单个“移动”按钮。
   - 普通实例和失败实例卡片中不再显示单个“移动”按钮。
   - 移动实例统一通过选中实例后使用顶部“移动”按钮完成。
   - 顶部批量移动能力继续保留，可用于单选或多选。

4. 保存区实例扩大选中触发区。
   - 点击提示词框左侧的实例编号/日期/时间区域，可以切换当前实例选中状态。
   - 点击按钮、输入框、图片、标签、下拉菜单等交互控件时，不误触发选中。
   - 生成中实例仍然不能参与批量选择。

5. 操作区右侧信息显示区限制高度。
   - 右侧状态/信息区域不再超过当前操作区高度。
   - 内容过长时默认只显示最后几句。
   - 鼠标悬停时显示完整大浮窗，浮窗可以覆盖周围区域，并尽量自动增高，超过上限后再滚动。

6. 手动实例“复制提交”改为“提交”。
   - 手动新增实例的按钮文案由“复制提交”改成“提交”。
   - 点击“提交”直接提交当前手动实例本身，不再新增一条复制实例。
   - 如果当前手动实例已经有输出图，直接报错，不重复提交。
   - 提交后当前实例移动到保存区最前面并显示读秒。
   - 生成成功后把输出图补回该实例；生成失败后保留该实例失败状态，便于继续处理。
   - 非手动生成实例继续使用“复制提交”；失败实例继续使用“重新提交”。

7. Provider 内部编号规则扩容。
   - 旧 Provider 内部编号不改。
   - 新建 Provider 自动生成更长且不易冲突的内部编号。
   - 内部编号继续只读显示，不再需要手动填写。

8. 操作区去掉输出图框。
   - 操作区不再显示“输出图”图片区。
   - 生成结果只显示在保存区实例和历史记录中。
   - 释放出的横向空间优先给输入图区域。

## 不修改内容

- 不改数据库 schema。
- 不改 OpenAI 脚本核心请求逻辑。
- 不改缩略图缓存生成和清理逻辑。
- 不改历史记录高级查询和清理规则。
- 不改标签管理中心的重命名、合并规则。
- 不改数据安全页备份、导出、恢复流程。
- 不改 Provider 能力体系和已有调用方式。

## 兼容与副作用

- 设置候选只记录成功值，所以新填写的 `api_key_env`、`model`、`user_agent` 必须至少成功生成一次后才会出现在下拉候选中。
- 自定义路径下拉比原生 `datalist` 多一些前端状态，需要重点检查输入、选择、失焦关闭、长路径显示。
- 去掉单个“移动”按钮后，移动单个实例需要先选中再点顶部“移动”，操作多一步，但保存区卡片更紧凑。
- 手动实例“提交”会改变当前实例本身的状态；如果失败，该实例会变成失败实例，而不是额外产生一条失败副本。
- 操作区去掉输出图后，用户需要在保存区或历史记录查看生成结果；这与前序版本“不再把结果回填操作区”的方向一致。

## 验证重点

- 设置页 `api_key_env`、`model`、`user_agent` 能手动输入，也能从成功候选中选择。
- 生图成功后会记录三类设置候选和生成路径候选，失败时不记录。
- 操作区生成路径长下拉完整显示，不破坏操作区布局。
- 保存区实例中不再出现单个“移动”按钮，顶部“移动”仍可用。
- 点击实例左侧编号/日期区域可以选中实例，点击控件不会误选。
- 手动实例无输出图时显示“提交”，有输出图时报错不提交。
- 手动实例提交后原实例进入生成中并移动到最前面，成功后补输出图。
- 操作区不再显示输出图框，输入图区域获得更多横向空间。
- 全量测试通过。
