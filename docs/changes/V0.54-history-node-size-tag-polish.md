# V0.54 历史浮窗、节点下拉、尺寸显示与标签筛选收口

## 目标

当前 V0.53 已完成历史记录页布局压缩、分页位置调整、Provider 下拉排序统一和历史浮窗空白修复。本版 V0.54 不新增大业务功能，继续修复实际使用中的交互细节和显示一致性问题，重点包括历史浮窗 ESC 关闭、节点下拉关闭规则、尺寸显示格式、历史记录摘要精简、历史页标签筛选体验。

本版原则：

- 不新增数据库 schema。
- 不改变生成、保存、历史记录写入流程。
- 不改变 V0.52/V0.53 已确定的筛选能力、编号规则和 Provider 排序规则。
- 不删除电脑上的图片文件。
- 尺寸前缀 `1K / 2K / 4K` 只通过软件固定映射表判断，不通过宽高反推。
- 文档确认后再执行实现；本文档落成不等于直接开始改代码。

## 修改项

### 1. 历史浮窗固定后支持 ESC 关闭

当前需求：

- 历史记录页中，浮窗显示错误信息时，鼠标点击浮窗会定住。
- 保留这个固定停留功能。
- 新增：浮窗定住时，按 `Esc` 可以退出浮窗。

调整方案：

- 保留现有：
  - 鼠标悬停显示浮窗。
  - 点击显示框后浮窗固定。
  - 点击其他区域关闭浮窗。
  - 切换页面时关闭浮窗。
- 新增键盘逻辑：
  - 当存在固定历史浮窗时，按 `Esc` 关闭历史浮窗。
  - 只关闭历史浮窗，不顺带触发其他历史页筛选或翻页动作。
- 处理快捷键优先级：
  - 如果图片弹窗、确认弹窗、批量弹窗、路径替换弹窗等更高优先级弹窗存在，`Esc` 先按这些弹窗原有逻辑处理。
  - 如果没有这些弹窗，而历史浮窗固定存在，再关闭历史浮窗。

验收标准：

- 点击历史错误框后，浮窗能固定停留。
- 固定浮窗存在时按 `Esc`，浮窗关闭。
- 非固定的悬停浮窗不受影响。
- 图片弹窗、确认弹窗、标签下拉、节点下拉等已有 `Esc` 行为不被破坏。

### 2. 历史记录页每页数量移动到分页区

当前需求：

- 历史记录页中，将每页数量框放到总数的左边挨着。
- 历史记录页中，开始日期被挤占，没有显示完全。

调整方案：

- 历史页顶部布局在 V0.53 基础上调整为：
  - 第一行：
    - 提示词搜索
    - 刷新
  - 第二行：
    - 标签
    - 状态
    - Provider
    - 尺寸
    - 模式
    - 调用方式
    - model
  - 第三行：
    - 左侧：开始日期、结束日期
    - 右侧：每页数量、总数、首页、上一页、下一页、尾页
- 每页数量从第一行移到分页工具组，放在“总数”左边。
- 日期控件保留足够宽度，不能被分页区挤压到显示不全。
- 窄屏时允许分页工具组换行，但不能出现横向滚动条。

验收标准：

- 每页数量紧挨总数左边。
- 开始日期和结束日期显示完整。
- 总数、首页、上一页、下一页、尾页仍在结束日期同一行靠右，空间不足时自然换行。
- 翻页和每页数量切换功能不回退。

### 3. 节点下拉点击外部关闭

当前需求：

- 生图管理页中，节点下拉框出现时，点击下拉框以外应该关闭下拉框。

调整方案：

- 增加节点下拉的外部点击关闭逻辑。
- 点击以下区域不关闭节点下拉：
  - 当前节点下拉框内部
  - 节点下拉触发按钮/选择框
  - 节点右键菜单内部
  - 节点新建/重命名弹窗内部
- 点击其他页面区域时，关闭所有节点下拉。

验收标准：

- 节点下拉打开后，点击外部区域会关闭。
- 点击下拉菜单内部选择项时，仍按原有逻辑执行。
- 不影响保存区点击空白自动保存编辑中实例的规则。

### 4. 去掉节点行标题“节点”

当前需求：

- 生图管理页中，节点行的标题“节点”两个字去掉。

调整方案：

- 节点行不再显示单独的“节点”文字标题。
- 保留节点下拉框本身的当前选择内容，例如“全部”“其他”或真实节点名。
- 不改变节点行横向布局和节点层级下拉逻辑。

验收标准：

- 节点行不再显示“节点”标题。
- 节点当前选择仍清楚可见。
- 节点新增、进入子节点、返回层级、全部/其他逻辑不回退。

### 5. 节点右键菜单与下拉关闭规则

当前需求：

- 生图管理页中，节点行的下拉菜单里，右键弹窗出现时，下拉菜单不要消失。
- 当右键弹窗出现时，点击下拉框以外，应该可以关闭下拉框和这个弹窗。

调整方案：

- 在节点下拉真实节点项上右键时：
  - 打开节点右键菜单。
  - 保持当前节点下拉菜单打开。
- 点击节点右键菜单内部：
  - 不关闭节点下拉。
  - 继续允许点击“重命名”“删除”。
- 点击节点下拉和右键菜单以外：
  - 同时关闭节点下拉。
  - 同时关闭节点右键菜单。
- 点击“重命名”后：
  - 节点下拉和右键菜单可关闭，进入重命名弹窗。
- 点击“删除”后：
  - 按原有二次确认规则执行。

验收标准：

- 右键节点项后，下拉菜单仍在。
- 右键菜单出现时，点击外部能同时关闭下拉和右键菜单。
- 点击右键菜单内部不误关闭。
- 重命名、删除功能不回退。

### 6. 尺寸显示使用固定映射表加前缀

当前需求：

- 生图管理页筛选行的尺寸下拉框中，尺寸显示为例如 `1K：123x123`。
- 历史记录页筛选行的尺寸下拉框中，尺寸显示为例如 `1K：123x123`。
- 历史记录页记录摘要中的尺寸显示为例如 `1K：123x123`。
- 如果不是来自于 `1K / 2K / 4K`，就不要前面的 `1K：`。
- 下拉框宽度不变。

关键规则：

- 尺寸前缀只能通过软件固定映射表判断。
- 不通过宽高反推。
- 不因为某个宽高“看起来像 1K/2K/4K”就加前缀。
- 只有当该尺寸值在固定映射表中能明确找到对应清晰度时，才显示：
  - `1K：1024x1024`
  - `2K：1536x2048`
  - `4K：4096x4096`
- 如果尺寸值来自自定义尺寸或映射表没有记录，则只显示：
  - `123x123`

调整范围：

- 生图管理页尺寸筛选下拉选项显示文本。
- 历史记录页尺寸筛选下拉选项显示文本。
- 历史记录卡片摘要中的尺寸显示文本。

验收标准：

- 固定映射表内的尺寸显示 `1K/2K/4K` 前缀。
- 自定义尺寸不显示前缀。
- 下拉框宽度不因显示文本变长而改变。
- 筛选提交值仍然使用原始尺寸值，不使用带前缀的显示文本。
- 不影响实际生成尺寸和历史参数快照。

### 7. 历史记录摘要去掉 Adapter 字段

当前需求：

- 历史记录页下面的记录中，去掉 `Adapter：openai`。
- Provider 信息已经足够体现 Adapter。

调整方案：

- 历史记录卡片摘要不再显示 Adapter 字段。
- Provider 仍按 V0.51/V0.53 的规则显示显示名和 adapter 标记。
- 参数 JSON 原文中仍保留 adapter 快照，不删除历史数据。

验收标准：

- 历史记录卡片摘要不再出现 `Adapter：openai`。
- 参数弹窗/参数复制仍保留完整参数快照。
- Provider 显示不回退。

### 8. 历史记录页标签筛选改为保存区同款多选标签框

当前需求：

- 历史记录页中，筛选行的标签改成和生图管理页筛选行标签框一样的形式。
- 支持多选、可清除等。
- 标签框可以加宽。

调整方案：

- 历史记录页标签筛选复用或参考保存区标签筛选组件：
  - 支持多选。
  - 支持清空。
  - 支持虚拟“无”。
  - 勾选“无”时，取消其他标签。
  - 勾选其他标签时，取消“无”。
- 历史页标签来源：
  - 使用历史记录 `tags_json` 中实际出现的 TAG。
  - 旧历史缺少 TAG 快照时，可归入“无”。
- 历史页标签筛选请求走后端查询。
- 标签框宽度可比其他筛选项更宽，避免选中多个标签后拥挤。

验收标准：

- 历史页标签筛选可多选。
- 历史页标签筛选可一键清除。
- “无”是虚拟项，不写入真实 TAG。
- 标签选择后立即刷新历史记录。
- 旧历史缺少 TAG 快照时不报错。
- 生图管理页标签筛选不被改坏。

## 副作用与处理

- `Esc` 关闭固定历史浮窗需要处理快捷键优先级，避免误关图片弹窗或确认弹窗。
- 节点下拉外部点击关闭和右键菜单保留同时存在，事件边界要清楚，避免右键刚打开就被外部点击逻辑关闭。
- 每页数量移动到分页区后，窄屏可能换行；必须确保开始日期和结束日期仍显示完整。
- 尺寸显示加前缀只改显示文本，不能改筛选值和数据库中的尺寸值。
- 历史页标签多选框变宽后，需要检查历史筛选行不出现横向滚动。
- 去掉 Adapter 摘要字段后，用户如果需要完整 adapter 信息，仍可从参数弹窗/复制参数中查看。
