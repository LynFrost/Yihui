# V0.50.1 生成取消、下拉稳定、带入规则与快捷删除修复

## 目标

V0.50.1 是 V0.50 的稳定性补丁，继续在当前 V0.50 版本上修复实际使用中发现的过程问题，不新增大功能，不改变数据库 schema。

本版原则：

- 不删除电脑上的图片文件。
- 不改变 Provider 能力体系。
- 不破坏 V0.50 的保存区生成中底部显示、实例 Provider 提交、设置页脏状态。
- 优先解决生成中轮询导致的菜单消失、按钮偶发无效，以及取消生成显示时机。

## 修改项

### 1. 取消中仍正常读秒

- 保存区生成中实例点击“取消”后，仍然继续显示正常读秒。
- 取消按钮显示“取消中”并置灰，避免重复点击。
- 读秒只作为前端过程显示，不写入数据库。

### 2. 取消中不提前显示正式结果

- 点击取消后，只标记当前任务正在取消。
- 在取消流程真正结束前，保存区不提前显示该实例此轮的正式结果。
- 等后端最终确认成功、失败或取消完成后，再刷新保存区正式实例。

### 3. 生成中轮询不打断下拉菜单和按钮点击

- 当前有生成中实例时，后台轮询不能把已经点开的 Provider 菜单、路径下拉、TAG 下拉、节点下拉、尺寸/清晰度菜单等自动重绘关闭。
- 下拉菜单只在用户点选、按 ESC、切换页面、或点击菜单外区域时关闭。
- 当前有生成中实例时，点击“带入”“清空”等按钮不能因为轮询重绘而偶发无效。
- 对其他保存区/操作区按钮也按同一规则避免被轮询打断。

### 4. 保存区和历史记录“带入”不改 Provider 和路径

- 保存区实例点击“带入”时，不改变操作区当前 Provider。
- 保存区实例点击“带入”时，不改变操作区当前生成路径。
- 历史记录点击“带入”时，同样不改变操作区当前 Provider 和当前生成路径。
- 带入仍复制提示词、输入图、标签、尺寸、清晰度、数量等可用参数。

### 5. 设置页新建 Provider 增加取消按钮

- 设置页“新建 Provider”旁边增加“取消”按钮。
- “取消”按钮的脏状态和“保存设置”一致：没有未保存修改时置灰，有未保存修改时可点击。
- 如果当前是新建但未保存 Provider，点击取消会放弃该草稿并回到原来的 Provider。
- 如果当前是已有 Provider 的未保存修改，点击取消会丢弃未保存修改并重新加载设置。

### 6. 保存区选中实例支持 Delete 删除

- 保存区有选中实例时，按键盘 Delete 等同点击上方“删除”批量操作。
- 仍然弹出删除确认。
- 仍然不删除电脑上的图片文件。
- 焦点在输入框、textarea、TAG 输入框、弹窗、下拉菜单、图片弹窗、设置页等区域时，不触发 Delete 删除。

## 副作用与处理

- 取消中仍显示读秒后，用户能继续看到等待时间；“取消中”主要体现在按钮文本和禁用状态。
- 轮询在用户操作菜单时会延迟整页重绘，生成中状态最多慢一轮显示，但可以避免菜单闪退和按钮点击丢失。
- 带入不改 Provider 和路径后，后续生成会按操作区当前 Provider 和路径执行，这和本版规则一致。
- Delete 快捷删除提高效率，但仍保留确认弹窗，误删风险可控。

## 验收重点

- 生成中点击取消后，读秒继续走，按钮显示“取消中”。
- 取消中期间不出现该轮正式结果，直到任务真正完成。
- 有生成中实例时，Provider、路径、TAG、节点等下拉不会自动消失。
- 有生成中实例时，“带入”“清空”等按钮点击有效。
- 保存区和历史记录带入均不改操作区 Provider 和路径。
- 设置页新建 Provider 后可取消草稿。
- 保存区选中实例后按 Delete 可触发批量删除确认。
