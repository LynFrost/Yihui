## 图片悬停临时预览

操作区和保存区实例的所有图片都支持鼠标悬停临时预览。

适用范围：

- 操作区输入图。
- 操作区输出图。
- 保存区实例输入图。
- 保存区实例输出图。

行为：

- 鼠标进入图片框时，显示该图片的大图临时预览。
- 鼠标离开图片框时，临时预览立即消失。
- 临时预览不支持缩放。
- 临时预览不支持左右切换。
- 临时预览不显示工具栏。
- 临时预览不改变当前点击大图弹窗的状态。

浮层规则：

- 使用独立的 hover preview 状态，不复用 click lightbox 的缩放、拖动和图库状态。
- 浮层使用固定定位或绝对定位，并设置足够高的 `z-index`。
- 浮层不得影响页面布局，不得触发横向溢出。
- 浮层图片使用 `object-fit: contain`，完整显示图片。
- 浮层最大宽度和最大高度不得超过当前视口可视区域。
- 鼠标移开图片后立即清空 hover preview 状态。

与点击大图弹窗的关系：

- 单击图片仍打开现有大图弹窗。
- 点击大图弹窗继续支持缩放、拖动、左右按钮切换、键盘左右方向键切换。
- 点击打开大图弹窗时，先关闭悬停临时预览。
- 悬停预览不改变 lightbox 的 gallery 列表，避免切换到其他实例图片。

## gpt-image-2 调用示例

当 `调用方式 = gpt-image-2` 时，调用示例使用：

```python
from openai import OpenAI
import base64

client = OpenAI(
    base_url=base_url,
    api_key=api_key,
)

prompt = operation_prompt

result = client.images.generate(
    model="gpt-image-2",
    prompt=prompt,
    size=resolved_size,
    quality="high",
    output_format="png",
    # output_compression only works for jpeg/webp
    # output_compression=80,
    background="auto",
    moderation="low",
    n=n,
    user="",
)

image_base64 = result.data[0].b64_json
image_bytes = base64.b64decode(image_base64)

with open("output.png", "wb") as f:
    f.write(image_bytes)
```

示例中不显示 `stream` 和 `partial_images`。

## response 调用示例

当 `调用方式 = response` 时，调用示例使用：

```python
from openai import OpenAI
import base64

client = OpenAI()

prompt = "Generate an image of gray tabby cat hugging an otter with an orange scarf"

response = client.responses.create(
    model="gpt-5.5",
    input=prompt,
    stream=False,
    tool_choice={"type": "image_generation"},
    tools=[
        {
            "type": "image_generation",

            # auto / generate / edit
            "action": "generate",

            # Responses API 里的图像工具模型；也可以省略用默认值
            "model": "gpt-image-1.5",

            # size 可选：1024x1024 / 1024x1536 / 1536x1024 / auto
            "size": "1024x1024",

            # quality 可选：low / medium / high / auto
            "quality": "high",

            # output_format 可选：png / jpeg / webp
            "output_format": "png",

            # 只对 jpeg / webp 有效；png 时通常不要启用
            # "output_compression": 80,

            # background 可选：transparent / opaque / auto
            "background": "auto",

            # moderation 可选：auto / low
            "moderation": "low",

            # stream=True 时可用，范围 0-3
            "partial_images": 0,

            # 以下是图生图 / 局部重绘时才用
            # "input_fidelity": "high",
            # "input_image_mask": {"file_id": "file-xxx"},
        }
    ],
)

image_data = [
    output.result
    for output in response.output
    if output.type == "image_generation_call"
]

if image_data:
    image_base64 = image_data[0]
    with open("otter.png", "wb") as f:
        f.write(base64.b64decode(image_base64))
```

说明：

- 这段代码按用户提供示例展示。
- `stream` 和 `partial_images` 只作为示例代码里的固定内容出现。
- `stream` 和 `partial_images` 不作为设置页参数表字段出现。
- `gpt-5.5` 和 `gpt-image-1.5` 在 V0.14 中先不做成可编辑配置。

## 后端生成调用

当 Provider 的 `adapter = openai` 时，根据 `openai_call_method` 选择调用路径。

当 `openai_call_method = gpt-image-2` 时：

- 沿用现有 Images API 调用逻辑。
- 操作区传入 `ratio` 和 `resolution_level`。
- 后端换算为 `resolved_size`。
- 调用时传官方 `size` 参数，不传假的 `resolution` 参数。
- `n` 使用操作区生成数量。

当 `openai_call_method = response` 时：

- 使用 Responses API 调用路径。
- V0.14 先按用户提供示例中的固定示例模型处理。
- 操作区提示词映射到 `input`。
- 操作区换算后的 `resolved_size` 映射到 image generation tool 的 `size`。
- `quality`、`output_format`、`output_compression`、`background`、`moderation` 使用 Provider 设置。
- `n` 不传入 response 调用路径。
- 如果实际接口返回多张图，保存逻辑沿用已有“多张图拆成多个实例”的规则。

如果 `adapter = google`：

- 保存配置允许。
- 点击生成时使用现有状态区域提示：

```text
Google adapter 暂未实现。
```

如果 `adapter = other`：

- 保存配置允许。
- 点击生成时使用现有状态区域提示：

```text
Other adapter 暂未实现。
```

## 副作用处理

设置页变紧凑后，说明文字减少。通过清晰字段名和禁用态占位文字保证基本可理解，不再额外增加说明段落。

`response` 与 `gpt-image-2` 的参数不完全一致。参数表必须根据 `调用方式` 动态切换，不把两套参数强行混在同一个列表中。

`stream` 和 `partial_images` 从参数表删除。`response` 示例代码中仍可保留用户提供的固定示例行，但它们不进入可编辑 Provider 配置。

悬停预览使用浮层实现。浮层不得占据布局空间，不得导致操作区或保存区实例高度变化。

标题增加版本号会改变标题行文字内容。除标题行之外，不得影响“生图管理”页操作区和保存区布局。

显示方式下拉顺序变化不得影响已保存的显示方式。保存和读取必须继续基于 `single`、`double` 等稳定值。
