# V0.70.1 操作区 Provider 下拉不透明修复

## 目标

V0.70.1 是 V0.70 的小补丁，只修复生图管理页操作区 Provider 自定义下拉菜单透明、看不清的问题。

## 根因

V0.70 新增的操作区 Provider 自定义下拉菜单背景使用了 `var(--surface)`，但当前 CSS 变量体系里没有定义 `--surface`。浏览器会丢弃这条无效背景声明，导致下拉浮层没有实际背景色，视觉上透出后方内容。

## 修改项

- 将 `.operation-provider-dropdown` 背景改为明确的不透明白色 `#fff`。
- 保留原有边框、阴影、圆角和 `√ / X` 标记交互。
- 增加静态回归测试，防止 Provider 下拉浮层再次缺少不透明背景。

## 不做内容

- 不改变 Provider 标记功能。
- 不改变 Provider 选择逻辑。
- 不改变 Provider 配置、数据库、导出、备份、恢复。
- 不改变其他页面或其他 Provider 下拉菜单。

## 验收重点

- 打开操作区 Provider 下拉菜单时，菜单背景不透明，不透出后方文字或实例内容。
- `√ / X` 标记仍可点击切换，且不会切换 Provider。
- 点击 Provider 行主体仍正常切换 Provider。
- 点击外部和按 ESC 仍能关闭下拉菜单。
