# V0.47 保存区 Provider、原分辨率重提交与启动稳定性

## 版本目标

V0.47 在 V0.46 的基础上做稳定性收口：修复保存区手动实例 Provider 编辑体验，确保复制提交和失败实例重新提交使用原实例自己的分辨率参数，并从脚本与启动器两侧提高生成稳定性和可观察性。

## 修改范围

1. 保存区实例来源显示精简
   - 将保存区实例中的“手动保存”显示为“手动”。
   - 只修改前端显示文案，不修改数据库中的 `source=manual`。

2. 保存区手动实例 Provider 编辑修复
   - 将手动实例 Provider 编辑控件从 `input + datalist` 改为真正的下拉选择。
   - 编辑时始终显示设置页中全部 Provider，不能因为当前值而只剩一个选项。
   - 下拉项显示内容和保存后的 Provider 显示保持一致。
   - 保存值仍然使用 Provider 内部编号，不保存显示名称。
   - 下拉菜单宽度按内容自动变长，不额外增加内部滚动条。

3. 复制提交使用原实例分辨率
   - `复制提交` 不再使用当前操作区的比例、清晰度、尺寸。
   - 优先使用原实例 `generation_params.ratio`、`generation_params.resolution_level`、`generation_params.resolved_size`。
   - 如果旧实例缺少参数，则从 `generation_size` 反推比例和清晰度。
   - 如果仍无法反推，最后才回退到当前操作区设置。
   - `复制提交` 仍然新增实例，生成数量固定为 1。

4. 失败实例重新提交使用原失败实例分辨率
   - 失败实例的 `重新提交` 使用该实例原本保存的分辨率参数。
   - `重新提交` 仍然复用失败实例本身，不额外新增实例。
   - 成功后将输出图回填到原失败实例。

5. 脚本侧提高容错和成功概率
   - 文生图和图生图共享脚本增加真实重试循环。
   - 识别并重试 `429`、`502`、`503`、`504`、timeout、connection reset、temporarily unavailable 等临时错误。
   - 尊重服务端 `retry_after`，没有明确值时使用退避等待。
   - 增加请求和下载超时配置，减少 4K、多图任务被过早判失败的概率。
   - 图片 URL 下载也加入重试，避免“生成成功但下载失败”。
   - 脚本将每次重试写入 `retry_events`，由后端写入历史记录。
   - 不自动降级 4K 到 2K/1K，避免改变用户指定结果。

6. 启动器端口占用处理
   - 当前 V0.46 在检测到 `8787` 已有服务时会打开网页后自动退出，导致旧服务窗口丢失时用户无法方便关闭端口。
   - V0.47 改为：检测到旧服务时显示 PID、进程名和启动命令。
   - 提示用户是否关闭旧服务并由当前 CMD 接管重启。
   - 用户确认后，关闭旧进程，等待端口释放，然后当前 CMD 启动 V0.47 服务。
   - 当前 CMD 成为真正服务窗口，之后关闭该窗口即可关闭端口。
   - 用户不确认时，不静默关闭窗口。

7. 运行日志
   - 启动器创建 `AI生图软件/logs` 目录。
   - Python 服务 stdout/stderr 同步写入版本日志文件。
   - 启动失败、运行崩溃时保留窗口并提示查看日志。

8. 生成中重试提示
   - 生成中实例如果进入失败重试等待，在提示词标题行显示红色 `第 x 次重试`。
   - 显示位置在“提示词”和“复制”按钮之间。
   - 保留当前读秒和输出图区状态。
   - 前端在存在生成中实例时轻量轮询实例状态，以便及时刷新重试提示。
   - 没有生成中实例时停止轮询。

## 副作用与取舍

- `复制提交` 和失败实例 `重新提交` 将不再跟随当前操作区分辨率。如果需要换分辨率重新生成，应先使用“带入操作区”，调整参数后再点击生成。
- 启动器接管旧服务时会结束旧 Python 进程。如果旧服务正在生成，用户确认接管会中断旧任务，因此必须二次确认。
- 增加脚本重试后，临时失败任务可能等待更久才最终失败，但生成中实例会显示重试次数，用户可以随时取消。
- 脚本重试可以显著提高短暂网络波动、502、下载失败时的成功概率，但无法保证服务商持续不可用时绝对成功。
- 运行日志会新增少量文本文件，便于定位 CMD 消失、后端异常和启动失败。

## 验收重点

- 手动实例来源显示为“手动”。
- 手动实例编辑时 Provider 下拉始终显示全部 Provider。
- Provider 下拉显示名、保存值、保存后展示一致。
- 原实例为 `3:4 / 2K` 时，复制提交和失败重新提交继续使用 `3:4 / 2K`。
- 脚本遇到可重试错误时会等待并重试，历史记录记录每次失败原因。
- 生成中实例重试时，提示词标题行显示红色 `第 x 次重试`。
- 如果 `8787` 已被旧服务占用，新 CMD 能关闭旧服务并接管启动。
- 关闭接管后的 CMD 能释放端口。
